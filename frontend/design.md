# ShowBuy 设计语言

**版本**: v2.3.3
**状态**: 正式版
**主题**: 亮色（暗色模式规划中）
**设计原则**: 温暖 · 精致 · 可信赖 · 涨势 · 专业 · 健壮


## Overview

ShowBuy 是一套专为个人全资产记账设计的视觉语言，基于现有代码实现提炼而成。不同于传统金融工具的冰冷与严肃，ShowBuy 追求 **"温暖的极简主义"** ——在保持专业、可靠、冷静的金融工具气质的同时，通过暖色基底、圆润形态和细腻质感，让"管钱"这件事变得从容、安心、有温度。

设计上融合了 Vercel Geist 的系统性与专业度，同时保留了 ShowBuy 独有的温暖情感与国内金融语境。


## Design Principles

1. **温暖 (Warm)**：暖奶油色背景 + 暖红珊瑚品牌色，中和金融产品的冰冷感
2. **精致 (Refined)**：大量留白 + 柔和阴影 + 大圆角，传递优雅质感
3. **可信赖 (Trustworthy)**：明亮的品牌色 + 极致的清晰友好，降低认知负担
4. **涨势 (Uptrend)**：品牌色 = 涨色 = 暖红，正向情绪强化
5. **专业 (Professional)**：高对比度 + 清晰信息层级 + WCAG AA 合规
6. **健壮 (Robust)**：设计系统需经得起极端场景检验——低对比度环境、宽屏显示器、暗色模式切换、字体降级。所有设计决策以"可落地、可维护、可扩展"为最终标准

### 功能色（金融涨跌 + 系统语义分离）

| 语义 | Token | 色值 | 用途 |
|------|-------|------|------|
| **涨（红）** | `--color-rise` | `#E34F38` | 盈利、上涨、正收益（与品牌色一致） |
| **跌（绿）** | `--color-fall` | `#7BC49A` | 亏损、下跌、负收益（柔和灰绿） |
| **危险（系统）** | `--color-danger` | `#D4364A` | 删除、错误、破坏性操作（独立于品牌红） |

> **设计决策**：品牌红（`#E34F38`）代表"涨 = 好事"，独立危险色（`#D4364A`）代表"删除 = 需谨慎"。两者在视觉上有明显区分，避免用户将"删除"与"好事"关联。
>
> **编码红线**：业务代码中**禁止直接调用 `--brand-*` 系列变量**。所有涨跌颜色必须通过 `--color-rise` / `--color-fall` 间接引用，确保暗色模式切换时全站自动同步。

## Spacing

基于 4px 基数，与现有 Tailwind 类名对齐。

### 间距体系

| Token | 值 | Tailwind | 用途 |
|-------|-----|----------|------|
| `--space-1` | 4px | `p-1` / `gap-1` | 图标与文字间距 |
| `--space-2` | 8px | `p-2` / `gap-2` | 紧凑内边距 |
| `--space-3` | 12px | `p-3` / `gap-3` | 小内边距 |
| **`--space-compact`** | **16px** | `p-4` / `gap-4` | **表格/列表/密集数据区** |
| `--space-5` | 20px | `p-5` / `gap-5` | 段落间距 |
| **`--space-standard`** | **24px** | `p-6` / `gap-6` | **卡片默认内边距** |
| **`--space-loose`** | **32px** | `p-8` / `gap-8` | **大卡片/区块间距** |
| `--space-12` | 48px | — | 页面边距（桌面） |
| `--space-16` | 64px | — | 页面边距（宽屏） |

### 使用原则
- **卡片默认**：`--space-standard`（24px）
- **表格/列表/筛选栏**：`--space-compact`（16px）
- **仪表盘/概览卡片**：`--space-loose`（32px）
- **垂直节奏**：正文行高保持宽松（如 16px/24px），提升长列表阅读舒适度
- **紧凑模式下的行高**：列表项高度保持 40px，不缩小，确保金融数据点击热区充足

## Elevation & Depth

所有阴影带有暖调（棕底），与奶油色背景协调。

| 层级 | Token | 阴影值 | 适用场景 |
|------|-------|--------|----------|
| 微凸起 | `--shadow-raised` | `0 2px 16px rgba(180, 150, 130, 0.06)` | 卡片、列表项 |
| 悬浮 | `--shadow-float` | `0 8px 32px rgba(180, 150, 130, 0.08)` | 下拉菜单、Popover |
| 模态 | `--shadow-modal` | `0 16px 48px rgba(180, 150, 130, 0.12)` | 抽屉、对话框 |

### 暗色模式预留

| Token | 亮色模式 | 暗色模式（规划） |
|-------|----------|------------------|
| `--shadow-raised` | 暖调阴影 | `inset 0 1px 0 rgba(255, 255, 255, 0.04)` |
| `--card-border` | `--border-light` | `1px solid rgba(255, 255, 255, 0.06)` |
| `--glow-brand` | `none` | `0 0 20px rgba(227, 79, 56, 0.2)` |

> **设计决策**：暗色模式下，层次感通过"边框提亮 + 内阴影"实现，而非依赖传统投影（在深色背景上容易呈现为脏污）。

### 暗色模式实现提示

> 品牌色的饱和度降低和涨跌色的提亮，建议通过 CSS 自定义属性（HSL 色值）动态计算，而非硬编码独立色值。具体实现方案将在 `/frontend/design.dark.md` 中详细定义。


## Focus & Accessibility

所有可交互元素在 `:focus-visible` 状态下必须显示 Focus 环。

```css
--focus-ring: 0 0 0 2px var(--bg-card), 0 0 0 4px var(--brand-700);
```

- 内层环（2px）：与卡片背景色一致，制造干净间隙
- 外层环（4px）：品牌色，指示焦点位置

> 禁止移除 `outline` 而不提供替代视觉指示。所有交互元素需附带 `aria` 标签。

> **自动化测试约束**：所有 CSS 变量（颜色）变更必须通过 axe-core 或 Lighthouse 进行对比度回归测试，确保 WCAG AA 合规。禁止在无自动化验证的情况下修改 `--text-*` 或颜色相关变量。

| **软涨按钮** | `--brand-100` | `--brand-700` | `--brand-400` | 40px | 已选中/候补操作 |
| **软跌按钮** | `#F0F9F2` | `#38A354` | `#D4E8DB` | 40px | 已选中/候补操作 |

> **危险按钮交互补偿**：为弥补 `--color-danger: #D4364A` 视觉警示力不足的问题，采用"幽灵按钮 + 悬停填充"模式。

| 状态 | 背景 | 边框 | 文字 |
|------|------|------|------|
| Default | 透明 | `--color-danger` 1px | `--color-danger` |
| Hover | `--color-danger` | 无 | 白色 |
| Active | `--color-danger`（+ 半透明叠加层） | 无 | 白色 |

> **软按钮使用原则**：当一个页面需要同时展示多个操作时，主操作使用实心按钮，辅助操作使用软按钮，避免"红绿灯"式的视觉噪音。

> **软按钮反馈**：由于软按钮背景通透，点击时不进行位移（无 `translateY`），而是通过背景色加深（如 `--brand-100` → `--brand-200`）或边框消失来反馈，保持轻量感。

#### 按钮物理反馈

> 主按钮（Primary）在 `:active` 状态下增加 `transform: translateY(1px)`，配合阴影消失，模拟"按下被吸进去"的物理反馈。

```css
.btn-primary:active {
  transform: translateY(1px);
  box-shadow: none;
}
```

## Voice & Content

> 文案是设计的一部分，极致清晰和友好是财务工具的核心。

- **标题/按钮/标签**：动词 + 名词：`新建持仓`、`删除账户`、`导入交割单`，禁用 `确定`、`OK`
- **正文/说明**：完整句子：`该操作将删除所有关联交易记录`
- **错误提示**：描述问题 + 给出下一步：`导入失败，文件格式不匹配。请检查 CSV 列头是否包含"交易日期"`
- **成功提示**：直接陈述结果：`持仓已删除`、`导入完成（12 条记录）`
- **进行中**：动词 + 省略号：`导入中…`、`计算中…`
- **空状态**：指向第一个行动：`暂无持仓，点击"新建持仓"开始记录`
- **数字**：阿拉伯数字 + 货币符号（`12 条记录`、`¥3,245.67`）
- **语气**：温暖、直白、不卑不亢。不说「请」，不说「非常」，不说「卓越」
- **涨势语言**：多用「收益」「增长」「积累」，少用「亏损」「风险」

### 数字格式规范

| 规则 | 标准 | 示例 |
|------|------|------|
| 千分位分隔符 | 使用逗号 | `¥12,345.67` |
| 小数点位数 | 金额保留 2 位 | `¥3,245.67` |
| 份额/数量 | 保留 2 位 | `1,234.56 份` |
| 百分比 | 保留 2 位，带 `%` | `+12.34%` |
| 负数 | 使用减号 `-` | `-¥1,234.56` |
| 零值 | 统一格式 | `¥0.00` 或 `0.00%` |
| **超大数值（≥1 亿）** | 默认显示完整数字，可选"缩写模式" | `¥123,456,789.00` → `¥1.23亿` |
| **负数会计模式** | 默认使用减号 `-`，未来可扩展括号模式 | `-¥1,234.56` → `(¥1,234.56)` |

> **实现约束**：缩写模式为全局开关（用户偏好设置），默认关闭，显示完整数字。

## Dark Mode（规划中）

暗色模式将遵循以下方向：

| 维度 | 亮色模式 | 暗色模式（规划） |
|------|----------|------------------|
| 页面背景 | `#FDFBF7`（暖奶油白） | `#1A1816`（深灰） |
| 卡片背景 | `#FFFFFF`（纯白） | `#242120`（稍亮灰） |
| 卡片边框 | `--border-light` | `1px solid rgba(255, 255, 255, 0.06)` |
| 卡片阴影 | `--shadow-raised` | `inset 0 1px 0 rgba(255, 255, 255, 0.04)` |
| 品牌色 | `#E34F38`（暖红珊瑚） | 饱和度降低 20% |
| 涨色（`--color-rise`） | `#E34F38` | `#F06B57`（稍亮） |
| 跌色（`--color-fall`） | `#7BC49A` | `#5DAF85`（稍亮） |
| 主文字 | `#2D2A24`（暖黑） | `rgba(237, 234, 229, 0.92)`（暖灰白，避免光晕） |
| 品牌发光 | `none` | `0 0 20px rgba(227, 79, 56, 0.2)` |

> **核心原则**：
> - 非纯黑背景，使用深灰层级
> - 品牌色饱和度降低，避免在暗色背景上"震动"
> - 阴影消失，发光 + 边框提亮 + 内阴影替代
> - 所有涨跌颜色通过 `--color-rise` / `--color-fall` 变量自动切换

> **暗色模式实现提示**：品牌色的饱和度降低和涨跌色的提亮，建议通过 CSS 自定义属性（HSL 色值）动态计算，而非硬编码独立色值。具体实现方案将在 `/frontend/design.dark.md` 中详细定义。


## Do's & Don'ts

**Do:**
- 用暖奶油色背景（`--bg-page: #FDFBF7`）
- 用大圆角（12–16px）和胶囊形状
- 用大量留白让数据呼吸
- 用暖红珊瑚作为品牌色（涨 = 好事）
- 用独立危险色（`#D4364A`）表示删除/错误
- 核心位置（总资产）用 Inter + 字重 600 建立视觉锚点
- 所有金额使用等宽字体 + `tabular-nums`
- 正负符号与数字保持同色（涨红跌绿）
- 图表颜色通过 `getComputedStyle` 动态读取
- 所有可交互元素显示 `:focus-visible` 环
- 保持 WCAG AA 对比度（正文 ≥ 4.5:1）
- 主按钮 `:active` 增加 `translateY(1px)` 物理反馈
- 软按钮点击时**不位移**，仅背景加深或边框消失
- 卡片内分割线使用 `--border-subtle` 降低视觉权重
- **所有 CSS 变量（颜色）变更必须通过 axe-core 或 Lighthouse 进行对比度回归测试**

**Don't:**
- 不使用 Georgia（衬线体）
- 不用冷白色或灰白色作为主背景
- 不用小圆角（<6px）作为卡片圆角
- 不用绿色传递正面情绪（国内语境绿 = 跌）
- 不将危险色（删除）与品牌色（涨）混用
- 不在暗色模式下简单反转亮度
- 不用颜色作为唯一信息载体（涨跌配 `+`/`-` 符号）
- 不直接调用 `--brand-*` 变量，通过 `--color-rise` / `--color-fall` 间接引用
- 不将 `--text-tertiary` 大面积直接置于 `--bg-page` 上
- **不跳过自动化对比度测试直接修改颜色变量**
