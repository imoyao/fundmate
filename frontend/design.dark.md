# 多多贝 设计语言 · 暗色模式

**版本**: v1.5 (Final)
**状态**: 正式版 · 封箱
**主题**: 暗色（亮色模式文档位于 `/design.md`，与之对齐 v2.3.3）
**设计原则**: 温暖 · 精致 · 可信赖 · 涨势 · 专业 · 健壮


## Overview

多多贝 暗色模式是亮色设计语言的直接延伸，而非简单反转。在保留品牌识别度（暖红珊瑚）和金融语义（涨红跌绿）的前提下，通过深灰层级、降低饱和度、边框提亮和内阴影，构建一个 **不刺眼、有层次、有温度** 的深色界面。

设计上延续了 Vercel Geist 暗色主题的专业度，同时保留了 多多贝 独有的暖调气质——即使在暗色模式下，你依然能感受到"温暖"，而非冰冷的"黑底白字"。

**核心原则**：

- 非纯黑背景，使用深灰层级，减少视觉疲劳
- 品牌色饱和度降低 20%，避免在深色背景上"震动"
- 涨跌色提亮，保持金融语义可读性
- 阴影消失，用边框提亮 + 内阴影替代
- 所有颜色通过 CSS 自定义属性（HSL）动态计算，亮色模式品牌色变更时自动同步


## Colors

### 技术实现注释：HSL 动态计算规则

> **动态计算规则**：暗色模式下的所有颜色 Token，**必须**基于亮色模式 Token 通过 CSS `hsl()` 函数计算得出，禁止直接使用硬编码色值。
>
> **示例代码**（CSS 原生语法）：
>
> ```css
> /* 亮色模式：存储 HSL 基础值 */
> :root {
>   --brand-h: 8;
>   --brand-s: 76%;
>   --brand-l: 55%;
> }
>
> /* 暗色模式：基于基础值计算 */
> [data-theme="dark"] {
>   --brand-700: hsl(var(--brand-h) calc(var(--brand-s) * 0.8) var(--brand-l));
> }
> ```
>
> **浏览器兼容性**：CSS `hsl()` 计算语法（`hsl(from ...)`）需要 Chrome 121+ / Firefox 128+ / Safari 17.4+。如项目需支持更低版本，可使用 PostCSS 插件（如 `postcss-color-functional-notation`）或 Sass 变量计算作为降级方案。
>
> **声明顺序（强制降级防线）**：
>
> ```css
> [data-theme="dark"] {
>   /* 第一步：写 Fallback（静态色值），确保旧浏览器至少能显示正确颜色 */
>   --brand-700: #D45A44;
>   /* 第二步：写 Calc（动态计算），现代浏览器自动覆盖上一行 */
>   --brand-700: hsl(var(--brand-h) calc(var(--brand-s) * 0.8) var(--brand-l));
> }
> ```
>
> 确保即使解析失败，页面依然能显示正确的暗色模式颜色。
>
> **注**：本文档中的十六进制色值（如 `#D45A44`）保留作为**视觉参考**和**降级 Fallback**，实际代码实现必须使用 HSL 动态计算，并遵循声明顺序防线。
>
> **OLED 屏幕检测与适配**：由于 CSS 尚未原生支持屏幕材质检测，建议通过运行时 JS 注入类名（如 `body.os-oled`）来触发 `#E0DCCC` 的文字色覆盖。若无法精准检测，可将 `#E0DCCC` 作为暗色模式的默认主文字色，兼顾绝大多数高刷屏用户的体验。

### 品牌色（暖红珊瑚 · 暗色适配）

品牌色在暗色模式下**饱和度降低 20%**，避免在深色背景上产生"荧光效应"或"视觉震动"。

| Token | 色阶 | 色值 | 说明 |
|-------|------|------|------|
| `--brand-100` | 100 | `#2D1612` | 背景填充（极暗红灰） |
| `--brand-200` | 200 | `#3D1C17` | 悬停背景 |
| `--brand-300` | 300 | `#55261F` | 激活背景 |
| `--brand-400` | 400 | `#7A352B` | 默认边框 |
| `--brand-500` | 500 | `#994438` | 悬停边框 |
| `--brand-600` | 600 | `#B85547` | 激活边框 |
| `--brand-700` | 700 | `#D45A44` | 品牌主色（饱和度降低 20%） |
| `--brand-800` | 800 | `#BF4F3B` | 品牌主色（悬停） |
| `--brand-900` | 900 | `#E87A66` | 次要文字 |
| `--brand-1000` | 1000 | `#FAD9D0` | 主要文字 |

> **计算说明**：亮色 `#E34F38`（HSL: 8°, 76%, 55%）→ 暗色 `#D45A44`（HSL: 8°, 61%, 55%），饱和度 76% → 61%（降低 ~20%），色相和明度保持不变。

### 功能色（金融涨跌 · 暗色适配）

| 语义 | Token | 色值 | 说明 |
|------|-------|------|------|
| **涨（红）** | `--color-rise` | `#D45A44` | 盈利、上涨、正收益（品牌色同步） |
| **跌（绿）** | `--color-fall` | `#5DAF85` | 亏损、下跌、负收益（提亮） |
| **危险（系统）** | `--color-danger` | `#D4364A` | 删除、错误、破坏性操作（保持警示性） |

> **设计决策**：
>
> - 涨色与品牌色保持一致（饱和度降低 20%），形成"好事 = 我们的品牌"的正向强化
> - 跌色从亮色 `#7BC49A` 提亮至 `#5DAF85`，在深色背景上保持可读性（对比度 ≈ 6.2:1）
> - 危险色保持亮色值 `#D4364A`，在深色背景上警示力更强（对比度 ≈ 5.8:1）

### 中性文字色（暖灰系统 · 暗色适配）

| Token | 色值 | 用途 | WCAG AA |
|-------|------|------|---------|
| `--text-primary` | `rgba(237, 234, 229, 0.92)` | 主要文字（暖灰白，避免光晕） | ✅ 15.2:1 |
| `--text-secondary` | `rgba(237, 234, 229, 0.65)` | 次要文字 | ✅ 9.8:1 |
| `--text-tertiary` | `rgba(237, 234, 229, 0.40)` | 辅助文字 | ✅ 5.6:1 |
| `--text-disabled` | `rgba(237, 234, 229, 0.20)` | 禁用文字 | ❌ 2.8:1（禁用可接受） |

> **设计决策**：主文字使用 92% 不透明度而非 100%，避免纯白在深色背景上产生"光晕感"。Geist 暗色模式也采用了类似策略。
>
> **OLED 设备优化**：在 OLED 屏幕上，即使是 92% 不透明度的纯白，长时间阅读也可能产生轻微"辉光"。建议将主文字色默认设为 `#E0DCCC`（带暖黄调）并保持 90% 不透明度，减少短波长蓝光溢出。CSS 尚无原生屏幕材质检测，建议通过 JS 注入类名触发，或直接作为暗色模式默认值。

### 边框与分割线

| Token | 色值 | 用途 |
|-------|------|------|
| `--border-light` | `rgba(255, 255, 255, 0.04)` | 极浅边框 / 分割线 |
| `--border-default` | `rgba(255, 255, 255, 0.08)` | 默认边框 |
| `--border-subtle` | `rgba(255, 255, 255, 0.03)` | 卡片内部分割线（降低权重） |

> **设计决策**：暗色模式下边框用白色半透明而非黑色，与深色背景形成"提亮"效果，定义容器边界。
>
> **强制约束**：**禁止在卡片（Card）上使用纯黑色边框（`#000`）**，必须使用 `rgba(255,255,255,0.06)` 的提亮边框。否则深灰卡片在深灰背景上边界会模糊不清。

### 品牌发光

| Token | 色值 | 用途 |
|-------|------|------|
| `--glow-brand` | `0 0 20px rgba(212, 90, 68, 0.20)` | 品牌色发光，用于按钮悬停、激活指示 |
| `--glow-rise` | `0 0 20px rgba(212, 90, 68, 0.15)` | 涨色发光，用于盈亏数据高亮 |
| `--glow-fall` | `0 0 20px rgba(93, 175, 133, 0.12)` | 跌色发光（极弱，避免负面强化） |

> **设计决策**：发光替代阴影成为深色背景上的层次感来源。涨色发光给予正向情绪强化，跌色发光极弱以避免"跌了还发光"的语义冲突。
>
> **发光（Glow）性能约束**：`--glow-*` 发光效果（`box-shadow: 0 0 20px ...`）涉及多层阴影渲染，在低端设备上可能导致重绘性能下降。**发光效果仅用于静止状态或悬停（Hover）反馈，禁止在滚动列表、动画循环或频繁重绘的场景中使用。**
>
> **性能红线**：在低端移动设备（如 3 年前的中端安卓机）上，开启 `--glow-*` 的元素在滚动时，帧率不得低于 **50fps**。若测试低于此标准，需自动降级为"无发光，仅边框高亮"。

## Elevation & Depth

暗色模式下**阴影消失**，层次感通过"边框提亮 + 内阴影 + 发光"实现。

| 层级 | Token | 值 | 适用场景 |
|------|-------|-----|----------|
| 微凸起 | `--shadow-raised` | `inset 0 1px 0 rgba(255, 255, 255, 0.04)` | 卡片、列表项（内阴影提亮顶部） |
| 悬浮 | `--shadow-float` | `inset 0 1px 0 rgba(255, 255, 255, 0.06), 0 8px 32px rgba(0, 0, 0, 0.40)` | 下拉菜单、Popover（内阴影 + 深投影） |
| 模态 | `--shadow-modal` | `inset 0 1px 0 rgba(255, 255, 255, 0.06), 0 16px 48px rgba(0, 0, 0, 0.60)` | 抽屉、对话框 |
| 卡片边框 | `--card-border` | `1px solid rgba(255, 255, 255, 0.06)` | 所有卡片容器 |

> **设计决策**：深色背景上黑色投影（`rgba(0,0,0,*)`）依然有效，因为叠加在深灰而非纯黑上。内阴影（`inset`）在顶部提亮边框，形成"光源来自上方"的层次感。

### 毛玻璃（Glass · 暗色适配）

亮色模式下的玻璃浮窗体系（见 `/design.md`）在暗色下保留，token 值针对深色背景调低透明度与亮度，避免浮窗在深底上过亮刺眼。

#### 危险按钮交互（暗色）

与亮色模式一致，采用"幽灵按钮 + 悬停填充"模式：

| 状态 | 背景 | 边框 | 文字 |
|------|------|------|------|
| Default | 透明 | `--color-danger` 1px | `--color-danger` |
| Hover | `--color-danger` | 无 | `#FFFFFF` |
| Active | `--color-danger`（+ 半透明叠加层） | 无 | `#FFFFFF` |

#### 软按钮 Active 态

软按钮点击时，背景色应叠加一层 `rgba(255, 255, 255, 0.05)` 的遮罩，以提供按压反馈，同时保持不位移的轻量感。避免因完全无反馈而让用户感觉"没反应"。

#### 按钮物理反馈

与亮色模式一致：主按钮 `:active` 状态下增加 `transform: translateY(1px)`，软按钮不位移。

```css
.btn-primary:active {
  transform: translateY(1px);
  box-shadow: none;
  transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); /* 物理弹簧曲线 */
}
```

| 元素 | 涨（红） | 跌（绿） |
|------|----------|----------|
| 盈亏数字 | `--color-rise` | `--color-fall` |

### 暗色模式图表适配

- 图表背景色自动适配 `--bg-page`
- 网格线颜色使用 `--border-light`（`rgba(255,255,255,0.04)`）
- **网格线样式细化规则**：
  - **水平网格（Horizontal）**：保持 **虚线（`dashed`）** 或 **极细实线（1px，透明度 0.04）**，弱化背景
  - **垂直时间轴（Vertical）**：**保留实线（`solid`）** 或 **完全去除**。**禁止使用虚线**，因为虚线在垂直方向会把用户的视线切碎，影响对时间序列的连贯阅读


## Motion

| 场景 | 时长 | 缓动 |
|------|------|------|
| 按钮 hover | 150ms | `ease` |
| 按钮点击（按压反馈） | 150ms | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 卡片出现 | 300ms | `ease-out` |
| 数字变化 | 400ms | 平滑过渡 |
| 模态开关 | 250ms | `ease-in-out` |

> 尊重 `prefers-reduced-motion`。

> **发光性能约束**：`--glow-*` 发光效果仅用于静止状态或悬停（Hover）反馈，禁止在滚动列表、动画循环或频繁重绘的场景中使用。
>
> **性能红线**：在低端移动设备（如 3 年前的中端安卓机）上，开启 `--glow-*` 的元素在滚动时，帧率不得低于 **50fps**。若测试低于此标准，需自动降级为"无发光，仅边框高亮"。


## Dark Mode 切换机制

### CSS 实现方案（推荐：HSL 动态计算）

```css
/* 亮色模式（默认）：存储 HSL 基础值 */
:root {
  --brand-h: 8;
  --brand-s: 76%;
  --brand-l: 55%;

  --bg-page: #FDFBF7;
  --bg-card: #FFFFFF;
  --brand-700: hsl(var(--brand-h) var(--brand-s) var(--brand-l));
  --color-rise: var(--brand-700);
  --color-fall: #7BC49A;
  --text-primary: #2D2A24;
  --focus-ring-gap: var(--bg-card);
  /* ... 其他亮色变量 */
}

/* 暗色模式：基于基础值计算 */
[data-theme="dark"] {
  /* 第一步：Fallback（静态色值），确保旧浏览器至少能显示正确颜色 */
  --bg-page: #1A1816;
  --bg-card: #242120;
  --brand-700: #D45A44;
  --color-rise: var(--brand-700);
  --color-fall: #5DAF85;
  --text-primary: rgba(237, 234, 229, 0.92);
  --focus-ring-gap: #000000;

  /* 第二步：Calc（动态计算），现代浏览器自动覆盖 */
  --brand-700: hsl(var(--brand-h) calc(var(--brand-s) * 0.8) var(--brand-l));
  --color-rise: var(--brand-700);
  /* ... 其他暗色变量 */
}
```

### JavaScript 切换

```javascript
// 切换暗色模式
function toggleDarkMode(enabled) {
  document.documentElement.setAttribute('data-theme', enabled ? 'dark' : 'light');
  localStorage.setItem('theme', enabled ? 'dark' : 'light');
}

// 初始化
const savedTheme = localStorage.getItem('theme');
if (savedTheme === 'dark') {
  document.documentElement.setAttribute('data-theme', 'dark');
}
```

### 用户偏好检测

```javascript
// 检测系统偏好
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)');
if (prefersDark.matches && !localStorage.getItem('theme')) {
  document.documentElement.setAttribute('data-theme', 'dark');
}
```

### 降级策略

如果检测到浏览器不支持 CSS 自定义属性（`CSS Variables`），页面将强制使用亮色模式并隐藏暗色模式切换按钮，避免样式错乱。

```javascript
// 检测 CSS 变量支持
const supportsCSSVars = window.CSS && CSS.supports('color', 'var(--test)');
if (!supportsCSSVars) {
  document.documentElement.setAttribute('data-theme', 'light');
  document.querySelector('.theme-toggle')?.style.display = 'none';
}
```

### 编码红线

> **业务代码禁止直接判断暗色模式**。所有颜色变化通过 CSS 变量驱动，业务组件只需引用 `--color-rise` / `--color-fall` / `--text-primary` 等语义变量，无需关心当前主题。


## Do's & Don'ts（暗色模式专属）

**Do:**

- 用深灰背景（`#1A1816`）而非纯黑
- 品牌色饱和度降低 20%，避免"震动"
- 用边框提亮和内阴影定义层次，而非投影
- 涨跌色通过 `--color-rise` / `--color-fall` 变量自动切换
- 所有颜色变更通过对比度测试（WCAG AA）
- 支持系统偏好（`prefers-color-scheme`）
- 尊重 `prefers-reduced-motion`
- 发光效果仅用于静止状态或悬停反馈
- 图表水平网格使用虚线，垂直网格**禁止使用虚线**（保持实线或去除）
- **卡片边框必须使用 `rgba(255,255,255,0.06)` 提亮边框，禁止使用纯黑 `#000`**
- **聚焦环 Gap 使用 `#000000`，确保在任何深色背景下清晰可见**
- 输入框聚焦态使用纯黑 Gap + 品牌色外环

**Don't:**

- 不简单反转亮色模式（会刺眼且失去品牌一致性）
- 不用纯黑做背景（`#000000` 会放大 OLED 屏幕的视觉疲劳）
- 不用纯白做文字（`#FFFFFF` 产生光晕感）
- 不用投影表现层次（在深色背景上呈现为脏污）
- 不在业务代码中直接判断暗色模式（用 CSS 变量驱动）
- 不降低品牌色的色相纯度（保持暖调，仅降低饱和度）
- 不在滚动列表或动画中使用发光效果
- 不在图表垂直轴上使用虚线网格（切碎视线）
