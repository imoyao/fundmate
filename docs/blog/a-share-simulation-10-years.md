# A股10年模拟实验：5种散户的最终命运（10000人数据）

> 用10年A股真实数据，模拟10000个不同交易风格的散户，揭示追涨杀跌、佛系定投、死扛加仓等策略的真实收益对比。

**交易策略 · 12 分钟阅读**
**发布于 2026-01-11**

## 实验背景与方法

我们用 A股 2015年1月1日至 2025年12月12日的真实数据，去掉 ST 股票后约 5000 支股票，对 5 种典型散户交易风格**各模拟 10000 人**，进行了长达 10 年的交易模拟。

**基准参考**：同期上证指数收益 **+16.08%**

这个实验揭示了一个残酷的真相：**你的交易风格，早已决定了你的命运。**

## 五种散户的10年结局

### 1. 随机乱买型 —— 平庸的大多数

> 没什么章法，看到什么买什么，该卖的时候就卖。

| 指标 | 数据 |
| --- | --- |
| 平均收益 | +5.29% |
| 中位数收益 | +0.54% |
| 盈利人数 | 5072/10000 (50.7%) |
| 跑赢上证 | 2856/10000 (28.6%) |
| 翻倍 | 120人 |
| 腰斩 | 24人 |

这是最"普通"的散户。10年下来，一半人赚一半人亏，但只有不到三成人跑赢了简单持有指数。

### 2. 佛系定投型 —— 最大赢家

> 上证3000点以下开始慢慢买，3000点以上开始慢慢卖。

| 指标 | 数据 |
| --- | --- |
| 平均收益 | +37.72% |
| 中位数收益 | +29.90% |
| 盈利人数 | 8633/10000 (86.3%) |
| 跑赢上证 | 6830/10000 (68.3%) |
| 翻倍 | 715人 |
| 腰斩 | 0人 |

::: tip
最简单的策略，却是最好的结果。**没有一个人腰斩**，近七成人跑赢指数。这就是纪律和耐心的力量。
:::

对应 TPI 人格：**SLCR（价值投资者）**、**ILCR（耐心观察者）**。

### 3. 追涨杀跌型 —— 韭菜收割机

> 涨了追进去，跌了恐慌卖。

| 指标 | 数据 |
| --- | --- |
| 平均收益 | -47.71% |
| 中位数收益 | -68.32% |
| 盈利人数 | 1034/10000 (10.3%) |
| 跑赢上证 | 787/10000 (7.9%) |
| 最高收益 | +8850.88% |
| 翻倍 | 274人 |
| 腰斩 | 7094人 (70.9%) |

::: warning
这就是大多数散户亏钱的原因。**七成人腰斩**，只有一成人盈利。但注意那个 +8850% 的幸运儿——追涨杀跌偶尔会产生"神话"，让你以为自己也能成为下一个。这就是幸存者偏差。
:::

对应 TPI 人格：**ITAE（阿修罗）**、**STAE（狂战士）**。

### 4. 死扛加仓型 —— 高风险高回报

> 越跌越买，一路补仓，回本就卖（类马丁格尔策略）。

| 指标 | 数据 |
| --- | --- |
| 平均收益 | +29.71% |
| 中位数收益 | +35.04% |
| 盈利人数 | 6804/10000 (68.0%) |
| 跑赢上证 | 6181/10000 (61.8%) |
| 最高收益 | +1497.47% |
| 翻倍 | 925人 |
| 腰斩 | 1102人 (11.0%) |

平均来看确实容易赚钱，这也是为什么很多人喜欢用这个策略。但 **11% 的腰斩率**意味着运气不好会死得很惨。最大亏损达到 **-98.72%**，比追涨杀跌的 -96.53% 还要惨。马丁格尔的本质是**用小概率的巨额亏损换取大概率的小额盈利**。

需要 **SLAR（战略投资者）**、**ILAR（远见者）** 的风险承受能力。

### 5. 手痒频繁交易型 —— 给券商打工

> 忍不住频繁操作，平均每年交易44次。

| 指标 | 数据 |
| --- | --- |
| 平均收益 | +14.26% |
| 中位数收益 | -3.03% |
| 盈利人数 | 4781/10000 (47.8%) |
| 跑赢上证 | 3668/10000 (36.7%) |
| 平均交易次数 | 444次 |
| 翻倍 | 940人 |
| 腰斩 | 937人 |

注意平均收益和中位数收益的巨大差距——说明收益分布极度不均，少数人赚大钱，大多数人小亏。频繁交易的问题不只是手续费，更重要的是**每次交易都是一次犯错的机会**。

对应 TPI 人格：**ITAR（机会主义者）**、**STAR（纪律日内交易者）**。

## 按交易人格的策略启示

### 情绪型（E型）：远离追涨杀跌

你最容易陷入追涨杀跌的陷阱。数据显示这是**最糟糕的交易风格**，70%的人会腰斩。

1. 建立严格的交易规则，不要临时决策
2. 使用自动止损，避免恐慌卖出
3. 考虑把资金交给定投策略

### 保守型（C型）：坚持佛系定投

佛系定投最适合你。86%的盈利率、0%的腰斩率，是最稳健的策略。

1. 利用你的耐心优势
2. 不要被短期波动影响
3. 坚持低买高卖的纪律

### 激进型（A型）：给死扛加仓设上限

死扛加仓可能很吸引你，因为平均收益不错。但请记住 11% 的腰斩率。

1. 一定要设置最大亏损上限
2. 不要把所有资金用于一个策略
3. 即使补仓也要有规则限制

## 结论：性格决定策略

这个10年模拟实验揭示了一个真相：**散户亏钱不是因为"运气不好"，而是因为选择了与自己性格不匹配的策略。**

追涨杀跌的人，本质上是无法控制情绪的 **ITAE 型**在用最差的方式交易。佛系定投的人，是 **SLCR 型**在用最适合他们的方式投资。了解你的交易人格，选择匹配的策略，这比任何技术分析都重要。
