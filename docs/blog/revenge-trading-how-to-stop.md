# 什么是复仇交易？如何停止这种自杀式行为

> 复仇交易是导致账户爆仓的主要原因之一。了解复仇交易的心理机制，学会识别和停止这种破坏性行为。

## 什么是复仇交易？

**复仇交易**（Revenge Trading）是指在经历亏损后，交易者试图通过激进交易"报复"市场、快速回本的行为。

## 危险信号

以下表现如果出现 **3 项以上**，你可能正在进行复仇交易：

| 信号 | 表现 |
| --- | --- |
| 加码 | 亏损后立即加大仓位 |
| 破计划 | 不遵守原来的交易计划 |
| 执念 | 觉得"市场欠我的" |
| 越亏越交易 | 越亏越想交易 |
| 情绪失控 | 出现愤怒、焦虑情绪 |
| 熬夜盯盘 | 熬夜盯盘想"扳回来" |

## 心理机制

**恶性循环**：亏损 → 愤怒/挫败 → 想要证明自己 → 加大仓位/频繁交易 → 更大亏损 → 更愤怒 → 循环...

背后的心理学原理：

1. **损失厌恶**：亏损的痛苦驱动冲动行为
2. **控制幻觉**：以为可以"掌控"市场
3. **沉没成本**：不愿接受已经亏损的事实
4. **自我价值感**：把亏损等同于个人失败

## 如何停止复仇交易？

### 1. 设置"熔断机制"

- 单日亏损达到 X%，强制停止交易
- 连续亏损 N 次，休息 24 小时
- 这些规则必须提前设定，不可临时修改

### 2. 建立"冷却期"规则

亏损后强制等待：

- **小亏（<1%）**：等待 15 分钟
- **中亏（1-3%）**：等待 1 小时
- **大亏（>3%）**：当天停止交易

### 3. 改变认知

- 亏损是交易的正常组成部分
- 没有人能 100% 盈利
- 重要的是长期期望值，不是单笔盈亏

### 4. 物理隔离

- 关闭交易软件
- 离开电脑
- 做其他事情分散注意力
