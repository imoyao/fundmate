## 什么是 FOMO？

FOMO (Fear Of Missing Out)，中文叫"错失恐惧"。在交易中，FOMO 表现为：

> "价格涨了这么多，我再不买就来不及了！"

然后你买在最高点，开始漫长的套牢之旅。

## FOMO 的进化根源

FOMO 不是缺陷，而是进化给我们的生存工具。在远古时代：

- 看到部落成员跑向某个方向？跟着跑，可能有食物
- 看到大家都在储存食物？你也储存，冬天不会饿死
- 错过群体行动？可能意味着死亡

这种"跟随群体"的本能在生存环境中是有益的。但在金融市场中，它变成了"追涨杀跌"的罪魁祸首。

## FOMO 的四种典型表现

| 类型 | 典型想法 | 心理机制 |
| --- | --- | --- |
| 价格型 | "已经涨了50%了，我现在不买以后更贵！" | 锚定效应，用过去价格判断现在的"便宜"或"贵" |
| 社交型 | "群里都在说这个币会涨10倍，我不买就亏了！" | 从众心理，社会证明 |
| 错过型 | "上次XX我没买，这次绝不能再错过！" | 后悔厌恶，过度补偿 |
| 时间型 | "这个机会稍纵即逝，必须马上行动！" | 稀缺性偏见，紧迫感制造 |

## 不同人格的 FOMO 易感度

| 人格类型 | FOMO易感度 | 原因 |
| --- | --- | --- |
| ITAE 阿修罗 | 极高 | 情绪驱动，直觉决策 |
| STAR 猎手 | 高 | 追求短期刺激 |
| ILAE 游侠 | 中高 | 直觉型，感性决策 |
| SLCR 面壁者 | 极低 | 系统化，长线思维 |

## 对抗 FOMO 的实用策略

### 1. 建立入场检查清单

在任何交易前，必须回答：

- [ ] 这笔交易在我的交易计划中吗？
- [ ] 我能承受最坏情况吗？
- [ ] 如果没有社交媒体的讨论，我还会买吗？
- [ ] 我是否已经冷静等待了至少1小时？

任何一项回答"否"，就不要交易。

### 2. "明天再说"规则

看到诱人的机会？告诉自己："如果这是真正的好机会，明天还在。" 90% 的 FOMO 冲动会在 24 小时内消退。

### 3. 限制信息摄入

- 关闭价格提醒
- 减少社交媒体时间
- 不加入"喊单群"

信息过载是 FOMO 的温床。

### 4. 接受错过

市场每天都有机会。错过一个，还有下一个。没有任何一笔交易是"必须做"的。

## FOMO vs 真正的机会

| FOMO冲动 | 真正的机会 |
| --- | --- |
| 紧迫感强烈 | 可以冷静分析 |
| 来自他人推荐 | 来自自己的研究 |
| 没有明确止损 | 风险可控可量化 |
| "这次不一样" | 符合一贯的交易系统 |

## 结论

FOMO 是人性的一部分，不可能完全消除。但通过建立系统、限制信息、接受错过，我们可以将 FOMO 对交易的影响降到最低。了解你的交易人格类型，是建立个性化 FOMO 对策的第一步。
