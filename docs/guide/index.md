## 说明

* **核心受众**：未来的你、你的家人

* **解决的痛点**：半年没用，回来忘了怎么操作。

* **建议内容**：

    * 如何启动系统（本地启动命令）。

    * 界面概览（首页仪表盘各模块是什么意思）。

    * 核心操作流程：如何新增一笔持仓、如何更新价格、如何导入 CSV、如何导出数据备份。

    * 常见问题排查（服务起不来怎么办？端口被占用怎么办？）。

    * **特点**：**纯实操截图 + 步骤**，不谈任何技术原理。
