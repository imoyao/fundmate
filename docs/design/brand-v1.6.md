### 设计理念补充：Alive（生命感）（v1.6 补充追加）

> 本补充不推翻 v1.6 终稿的既有决议，仅在"形态几何"层新增统一容器语言；四件品牌锚点（§1）及全部色彩/动效规范保持不变。

- **理念**：提出 "Alive（生命感）"——以 **n=3 超椭圆（Superellipse）** 轮廓替代直角方形，强调"科技与生命的融合"。
- **公式**：`|x|^n + |y|^n = 1`，取 `n=3`；归一化到容器半宽 `a`（a=b）即 `|x/a|^3 + |y/a|^3 = 1`。
- **几何语义**：`n=2` 为圆，`n→∞` 趋近于方；`n=3` 居中——曲线**无直线段**，圆润而具张力，天然传达"生命流动感"，比直角方更有机、比圆更显结构。
- **应用范围**：Logo 背景容器（§5）、图形母题容器、插画背景（§9）的外轮廓统一采用 n=3 超椭圆，作为"无直角"的容器语言；与既有圆角令牌（如卡片 `16px`、胶囊按钮 `9999px`）不冲突时优先采用。
- **锚点约束**：超椭圆仅是"直角/方正"的有机替代，不得削弱四锚点（①珊瑚红 ②暖奶油 ③鹦鹉螺螺线 ④有机动律）中任一。

## 1. 品牌定位与核心意象

- **母题：潮间带（Tidal Zone）**。投资像潮水——有涨落、有节律、长期向上。品牌气质：温暖、自信、可信——自信体现在用色大胆，可信体现在不煽动（不荐股、不跟单）。
- **核心符号：鹦鹉螺对数螺线（Nautilus Logarithmic Spiral）**。螺线的等角扩张天然隐喻"复利"——每一圈都比前一圈以相同比例放大。Logo 与装饰图形统一以对数螺线为母题。
- **四件品牌辨识度锚点（不可稀释）**：① 珊瑚红 `#E34F38`；② 暖奶油 `#FDFBF7`；③ 鹦鹉螺螺线；④ 涟漪/呼吸的有机动律。任何外部参考（含 monopo saigon 的液体感）的借用，都不得削弱这四点。

### 1.1 设计哲学：Alive（生命感）

- **主张**：科技产品易陷于冷硬、直角、机械感；"Alive" 用有机曲线把"科技"与"生命"缝合——品牌视觉应让人感到"在生长、在呼吸"，而非"被计算"。
- **形态几何**：所有**容器级外轮廓**（Logo 背景、图形母题框、插画底色、色块）由直角方形统一改为 **n=3 超椭圆**：`|x/a|^3 + |y/a|^3 = 1`。其曲线无直线段，介于圆与方之间，圆润中带张力，即"生命流动感"的几何来源。
- **与螺线母题的关系**：超椭圆是"壳"的容器，"圆中藏对数螺线"（§5）升级为"超椭圆中藏对数螺线"——外柔内旋，容器与母题同为有机曲线，强化统一生命感。
- **落地边界**：超椭圆用于"容器/底"，不替代螺线描边与珊瑚红主色；圆角令牌（`16px`/`9999px`）仍用于卡片与按钮，二者并存不悖。

**危险色使用约束**（避免与品牌红混淆）：① 仅用于删除/错误/破坏性操作，不与品牌红同处一个组件的相邻位置；② 与背景文本对比度 ≥ 4.5:1；③ 禁止用品牌红 `#E34F38` 表示"错误/删除"语义。

> **v1.6 决议 C**：删除原 `#F8F4EE`。所有原定使用 `#F8F4EE` 的场景（分隔模块底色、插画背景圆）一律复用 `#F5F0EB`。不再为营销页新增独立背景令牌，避免后人困惑。

### 3.2 浓度映射（v1.6 决议 F）

"浓度"指同一品牌色在不同用途下的明度/饱和度档位。开发阶段直接映射 design.md 色阶，无需自创取值：

| 用途 | 浓度 | 取值 | design.md 令牌 |
|:---|:---|:---|:---|
| 主色 / CTA / 关键数字 | 100% | `#E34F38` | `--brand-700` / `--color-rise` |
| 次级填充 / 浅色块 / 图表辅助 | 50–60% | `#FABDB0`–`#FDD9D0` | `--brand-400`–`--brand-300` |
| 极淡底色 / 氛围晕染 / 呼吸涟漪 | ~30% | `#FEEDE8`–`#FFF5F3` | `--brand-200`–`--brand-100` |

其余中间档位由前端按 design.md 完整色阶（`--brand-100`～`--brand-1000`）自行取用。

### 3.3 暗色模式

主站（营销/落地页）为**浅色优先，不提供暗色切换**：品牌以暖奶油 `#FDFBF7` + 珊瑚红构建，浅色是原生载体；落地页属"滚动即走"型，无长会话切换诉求，且参考站 monopo 亦为浅色。暗色策略**仅适用于工具站**（`frontend/design.md` / `frontend/design.dark.md`，经 `data-theme` 驱动，含系统偏好被动适配）。主站若未来需被动适配系统暗色，另行评估，不纳入 v1.6 范围。

### 3.4 主站用色策略：浅色优先，但用色大胆

主站画布保持浅色（暖奶油 `#FDFBF7`），但**用色要自信、有体量，拒绝"性冷淡风"**（近单色灰白极简）：

- 珊瑚红 `#E34F38` 不应只出现在按钮与描边——应以**大面积色块**承担视觉重心：整段 Hero 底色、全幅色带、实心色卡、大字号彩色标题。
- 浅水绿 `#7BC49A` 作副色，用于强调块、数据标签、液体动效第二色相，制造暖—冷对比的呼吸感。
- 浓度映射（§3.2）中的 30% 淡色仅用于极轻氛围晕染；主站主体应使用 100%（`#E34F38`）与 50–60% 档位建立明确色彩体量。
- 液体流动动效（§6.6）可用饱和珊瑚场而非淡 tint，强化品牌记忆。

> 平衡：大胆的是**用色面积与饱和度**，不是信息密度或煽动性文案。数据主权边界（不荐股、不跟单）的克制态度保持不变。

## 4. 字体系统（v1.6 决议 B）

- **主站字体家族（与 design.md 一致）**：`Inter`, `-apple-system`, `"PingFang SC"`, `"Microsoft YaHei"`, `system-ui`, `sans-serif`。

## 5. Logo 规范（v1.6 决议 D）

- **母题**：超椭圆（Superellipse, n=3）容器中藏对数螺线（鹦鹉螺），单笔连续路径，珊瑚红描边。
- **外轮廓（Alive 理念）**：Logo 背景容器由直角方形/圆形改为 **n=3 超椭圆**——归一化公式 `|x/a|^3 + |y/a|^3 = 1`（a 为容器半宽），曲线无直线段，体现"生命流动感"与科技—生命融合（详见 §1.1）。圆角语义自此以超椭圆为统一容器语言。
- **安全留白**：Logo 外扩 1/4 容器半宽留白（沿用圆轮廓留白比例，按超椭圆外接圆估算）。
- **最小尺寸**：建议 ≥ 24px；低于 16px 不保证可识别。
- **清晰度状态（v1.6 修订）**：
  > 目标：在 16–24px 尺寸下保持可识别。当前占位 SVG 为过渡版本（密集路径，24px 下可能糊成一片），**待正式 Logo 稿验证后回填**，不承诺既成清晰。
- **清晰度验证方法**（待正式稿时执行）：① 用 SVGOMG 压缩路径，控制锚点数量 ≤ 20；② 在 16px / 24px 下放大至 200% 检查无重叠、断裂；③ 导出 PNG 在移动端真机抽查可读性。验证结论回填本节。

- 主站与工具侧共用同一 Logo 母题，保证跨站识别一致。

## 6. 动效策略（v1.6 重写 · 规范级）

> **v1.4/1.5 复盘**：动效章此前为"描述性"，导致 AI/前端自取极保守值——涟漪 `opacity 0.05→0.15` 肉眼近乎不可见、滚动动效退化为无意义代码。本版改为**强制工程规范**：所有动效须达"可感知阈值"，且必须可降级。

### 6.1 设计原则

1. **有机而非机械**：动律取自潮间带——呼吸、涟漪、缓慢扩张，拒绝生硬弹跳。
2. **耐心缓动**：统一使用 `cubic-bezier(0.19, 1, 0.22, 1)`（expo-out 变体），起步柔、收尾缓，与主站"慢而可信"气质一致。
3. **可感知优先**：任何"装饰性"动效的可见度不得低到看不见（见 §6.4 下限）。
4. **被动触发优于自动循环**：内容区动效默认由滚动进入视口触发；仅品牌区（Hero）允许低强度自动呼吸。

### 6.2 缓动与时长基准

| 动效类型 | 缓动 | 时长 | 说明 |
|:---|:---|:---|:---|
| 品牌呼吸（Logo/涟漪） | `cubic-bezier(0.19,1,0.22,1)` | 6–8s | 无限循环，`alternate` |
| 滚动揭示（fade+位移） | `cubic-bezier(0.19,1,0.22,1)` | 0.6–0.9s | 进入视口触发一次 |
| 悬停反馈（按钮/卡片） | `ease-out` | 0.2–0.3s | 仅颜色/阴影/轻微位移 |
| 液体流动（goo 融合） | `cubic-bezier(0.19,1,0.22,1)` | 14–22s | 多 blob 错相位漂移 |

### 6.3 品牌区自动呼吸（Hero）

- **涟漪**：同心圆 2–3 圈，错相位扩张；`opacity` 下限 **0.12**、上限 **0.22**（严禁低于 0.1）。描边用 `--brand-700` 或 `--brand-400`。
- **Logo 呼吸**：`scale(1) → scale(1.03)`（幅度小于 1.05 以免喧宾夺主），6s 循环。
- 呼吸是"氛围"而非"信息"，强度克制。

### 6.4 可见度下限（硬约束）

| 动效 | 最低可感知标准 |
|:---|:---|
| 呼吸/涟漪透明度 | `opacity ≥ 0.12`（峰值 ≥ 0.20） |
| 滚动揭示位移 | `translateY(16–24px) → 0` 且 `opacity 0 → 1` |
| 悬停态反馈 | 颜色/阴影变化须肉眼可辨（对比差 ≥ 1.5:1） |

> 违反下限（如 `opacity 0.05`、`scale 1→1.02` 不可见位移）视为未达标，需在评审退回。

### 6.5 滚动揭示模式（内容区标准实现）

内容区动效统一用 IntersectionObserver，**进入视口触发一次 fade+上移**，离开不回放：

```js
const observer = new IntersectionObserver((entries) => {
  for (const e of entries) {
    if (e.isIntersecting) {
      e.target.classList.add('in-view');   // 触发一次后停止观察
      observer.unobserve(e.target);
    }
  }
}, { threshold: 0.15, rootMargin: '0px 0px -10% 0px' });

document.querySelectorAll('[data-reveal]').forEach(el => observer.observe(el));
```

```css
[data-reveal] { opacity: 0; transform: translateY(20px);
  transition: opacity .7s cubic-bezier(.19,1,.22,1), transform .7s cubic-bezier(.19,1,.22,1); }
[data-reveal].in-view { opacity: 1; transform: none; }
```

> **反例（v1.4 实际产出）**：某实现用 IntersectionObserver 仅 pause/resume Hero 涟漪——涟漪本就在首屏视口内，该代码无任何可见效果，属无效动效，禁止。

### 6.6 液体流动动效（可选 Hero 增强 · 借用 monopo 液体感）

可借用 monopo saigon 的"乳液流动"液体感，但**必须品牌重着色**：以珊瑚红→暖珊瑚浅调→浅水绿（`#E34F38 → #F2A38E → #7BC49A`）替代其薄荷/橙/牛血红虹彩，保留四锚点。

技术：SVG `feGaussianBlur` + `feColorMatrix`（拉高 alpha 对比）的 goo 融球滤镜，让多个色块像乳液般融合；多 blob 错相位慢漂（14–22s）。参考实现见仓库根目录 `demo-liquid.html`（已用品牌色验证，随本版交付）。

### 6.7 无障碍适配（v1.6 决议 A · 硬约束）

品牌区自动呼吸动效在 `prefers-reduced-motion: reduce` 下**必须降级为静态**，否则违反 WCAG 2.3.3（动画无障碍）：

```css
@media (prefers-reduced-motion: reduce) {
  .ripple, .logo-breathe, .blob { animation: none !important; }
  [data-reveal] { opacity: 1; transform: none; transition: none; }
}
```

内容区交互动效（滚动触发、悬停）不受影响，但须确保触发条件在降级后仍可正常操作（即内容默认可见，不依赖动画显示）。

## 7. 落地页结构（建议）

1. **Hero**：主标题 + 标准副标题 + CTA（珊瑚红胶囊按钮）+ 背景涟漪/液体呼吸。
2. **痛点→方案**：2×2 或 1×4 卡片网格，滚动揭示逐一淡入；图标由 Lucide / Heroicons 的 SVG 替换（禁 emoji，具体图标名待定）。
3. **诚实体验区**：开发者说 + 数据信任标签（0 广告 / 不自动抓取 / XIRR 精确）+ 用户证言。
4. **页脚**：Slogan 韵脚 + 数据主权声明 + 链接。

> 区块分隔底色统一 `#F5F0EB`（§3.1）。卡片圆角 `16px`，按钮圆角 `9999px`（胶囊）。

## 8. 品牌故事与数据主权

- **品牌故事**：定位为**独立页面**（`/about` 或 `/story`），非落地页站内锚点。落地页仅以"诚实体验区"片段引流。
- **数据主权边界**（不可妥协）：不荐股、不跟单、不预测市场；不自动抓取；数据可导出、不用于营销。所有文案与视觉须强化"数据在你手里"。

---

## 9. 图标与图形规范

- **禁止 emoji 作图标**（📊📈🔒🧾 等）。一律用 SVG 图标库（Lucide / Heroicons），统一 24×24 视图框。
- 图形母题统一鹦鹉螺螺线 / 同心涟漪，与 Logo 呼应。
- 图形母题与插画的**外轮廓容器**统一采用 n=3 超椭圆（Alive 理念，§1.1）：插画背景底、色块容器以 `|x/a|^3 + |y/a|^3 = 1` 替代直角方形/正圆；插画背景填充仍用 `#F5F0EB`（复用次级背景，不新增令牌）。
- 超椭圆仅作容器语言；螺线描边、珊瑚红主色与既有圆角令牌（`16px`/`9999px`）并存不冲突。

## 11. 给前端 / AI 的实现指引（防弱实现）

为避免 v1.4 再次出现"动效少且不可见"，落地时遵守：

1. 动效先用本文件 §6 的代码片段，不另起炉灶；缓动固定 `cubic-bezier(0.19,1,0.22,1)`。
2. 任何装饰动效自测可见度，低于 §6.4 下限即不合格。
3. 滚动揭示必须真正改变 `opacity` 与 `translateY`（参考 §6.5），不得只 pause/resume 已有动画。
4. 液体动效参考仓库根目录 `demo-liquid.html`，品牌重着色，不照搬 monopo 暗底虹彩。
5. 交付前用 `@media (prefers-reduced-motion: reduce)` 实测降级为静态。
6. 图标全量替换为 SVG，grep 确认无 emoji 残留。

## 13. 移动端适配参数（技术规范）

主站为响应式静态页，须满足：

- **响应式断点**：≤880px 两列网格降列；≤720px 单列、隐藏次级导航（保留主 CTA）；≤480px 全单列、按钮全宽。
- **触控区域**：按钮/可点击元素最小高度 **≥ 48px**，图标可点区域 ≥ 24px。
- **行高可读性**：正文行高 ≥ 1.5×字号（最小 24px）；标题行高 1.12–1.25。
- **间距与安全边距**：移动端元素最小间距 ≥ 8px；容器边距 `92vw`。
