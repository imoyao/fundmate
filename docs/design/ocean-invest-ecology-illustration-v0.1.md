# 多多贝 · 海洋投资生态图鉴 · 插画设计规范 v0.1

> 状态：本协议为**设计规范（文档）**，不含任何插画产出或前端代码。执行（绘制矢量插画、开发测试互动）一律后置到"后端上线 + 落地页/真实用户出现"之后，符合市场验证期"零成本、先验证"原则。
> 日期：2026-08-05
> 一句话：品牌名"贝"=古代货币/贝壳，海洋贝类图鉴是顺着品牌名长出的隐喻系统，不是硬凑 IP；值得做，但属"品牌/互动层"，先规范、后建造。

## 一、设计哲学锚点

- **Alive（生命感）**：让硬核表格/数字具备生气，用生物"习性"隐喻"投资者行为与风险偏好"。
- **词源一致性（关键优势）**：中文"贝"自古为货币（贝币）。"多多贝"之"贝"天然是"钱/资产"的隐喻载体。把用户映射为"不同贝类"，是品牌名的内禀延伸，而非外部贴皮——这是本方案比一般 fintech mascot 更站得住的根本原因。
- **克制基调**：理性克制 + 有机生命。绝不 3D 渲染，扁平几何。

## 二、海洋投资生态图鉴（8 生物）

（原提案 7 + 新增 1：珊瑚 / 分散配置）

### 1. 鹦鹉螺 Nautilus —— 品牌灵魂 · 最优投资者

- 习性：对数螺旋壳（黄金比）、精密气室主动调浮力、不抗拒洋流。
- 隐喻：长期复利主义者。不预测涨跌（潮水），只测算资产真实增长刻度（XIRR）。有定力。
- 标签：🧭 深度定力 · 测算复利
- 落位：首屏 / 品牌故事顶部，精神图腾。
- 评级：★最强（螺旋 = 复利曲线，天作之合）。

### 2. 角贝 Tusk Shell —— 长期定投者 / 潜伏者

- 习性：埋沙泥，两端细管滤水，潮间带至 7000m 皆有，与世无争。
- 隐喻：隐形定投人。时间换空间，不理短期浮盈浮亏，按节奏沉淀。
- 标签：⏳ 大隐隐于市 · 静待花开
- 落位：#scenarios 对应"基金定投 / 年金养老"。半埋沙、露呼吸管。

### 3. 扇贝 Scallop —— 波段交易者 / 灵活择时者

- 习性：数十眼感光影，开合喷水主动"跳跃"游动。
- 隐喻：主动择时 / 趋势交易。捕市场脉冲（光变），快速进出，追波段。
- 标签：⚡ 追光者 · 灵活跳跃
- 落位：#compare / #scenarios 对应"多账户波段 / 短期切换"。微张 + 水波纹。

### 4. 石鳖 Chiton —— 极端防御者 / 保守派

- 习性：背 8 硬甲如装甲，死吸附礁石，任浪拍不动。
- 隐喻：**行为上**本金绝对优先、极厌恶风险、不容忍回撤（风险厌恶）。
- 标签：🛡️ 固若金汤 · 绝对防守
- 落位：对应"只买货基 / 债基、极谨慎"用户。

### 5. 玉螺 / 红螺 Moon Snail —— 进攻型猎手 / 深挖价值者

- 习性：肉食，能在他贝壳钻规整圆洞吸食。
- 隐喻：深挖错杀价值、高风险偏好、强执行。
- 标签：🔎 破壁者 · 价值猎杀
- 落位：对应"深研个股 / 可转债"。**视觉修订见 §三.1**：只画"角轻触外壳"，不出现血肉 / 猎杀；文案用"钻探错杀价值"。
- 评级：隐喻聪明，原生视觉偏攻击，需柔化。

### 6. 船蛸 Paper Nautilus / Argonaut —— 初期新手 / 脆弱投资者

- 习性：雌章鱼分泌极薄纸壳孵卵，一捏就碎。
- 隐喻：刚入市新手，保护层薄、抗风险弱。
- 标签：🌱 薄壳守护 · 新手进化
- 落位：#scenarios 对应"学生 / 刚工作定投"。透明半壳小章鱼，脆弱可爱。
- **修订见 §三.3**：船蛸实为头足类（章鱼），非贝；别名"纸鹦鹉螺"易与 1 号混淆。建议归为"章鱼系 / 脆弱新手"独立支线并标明，或换真·贝类新手。

### 7. 宝贝螺 Cowrie —— 囤积型价值守护者

- 习性：壳滑亮，曾作古代货币。
- 隐喻：**资产上**极重现金流 / 储蓄，偏好安全、流动、保值（现金为王）。
- 标签：💰 财富储蓄 · 现金为王
- **分界见 §三.2**：与 4 号石鳖都偏"保守"，必须写清——石鳖 = 行为风险厌恶（不容忍回撤），宝贝螺 = 资产现金偏好（流动性优先）。二者不同维度。

### 8. ★新增 珊瑚 Coral —— 分散 / 资产配置者

- 习性：无数独立水螅体组成 colony；单体脆弱、群体抗风浪。
- 隐喻：分散配置、不押单一资产；个体脆弱靠组合抗风险。
- 标签：🪸 众木成林 · 分散为王
- 落位：对应"资产配置 / 定投组合 / 不 all-in"。补齐行为矩阵最关键缺口（别把蛋放一个壳里）。

## 三、对原映射的三处修订

1. **玉螺视觉柔化**：保留"破壁者"精神，插画去血腥（不绘血肉 / 猎杀），文案改"钻探错杀价值"，避免消费级 app 的攻击性观感。
2. **石鳖 ↔ 宝贝螺 分界写死**：石鳖 = 风险厌恶（行为），宝贝螺 = 现金偏好（资产）。否则用户见两个"保守贝"会混淆。
3. **船蛸命名 / taxonomy 清理**：标明其为章鱼（头足类）非贝；或换真贝类新手。避免与鹦鹉螺混淆、也避免向用户传递错误生物分类。

## 四、缺失 archetype（已补 §二.8 珊瑚）

原 7 个覆盖：保守 / 现金 / 复利 / 定投 / 择时 / 深挖 / 新手。关键缺口 = **分散配置**。珊瑚补齐。

## 五、视觉规范（对齐 v1.7 标准）

- 外框：**n=3 超椭圆**（统一裁切 / 外轮廓）。
- 主色：**珊瑚红 #E34F38**；点缀：**浅水绿 #7BC49A**。双色克制。
- 风格：**扁平几何 + 单线描边**，绝不用 3D 渲染。
- 形态：有机生命感但理性克制。

## 六、颜色双账原则（重要）

- 品牌点缀：珊瑚红 + 浅水绿（仅装饰 / 识别）。
- 盈亏语义：**A 股"红涨绿跌"**，红 = 盈利。品牌珊瑚红**不得**承担盈亏语义，避免"品牌红 = 永远涨"的误读或与环境盈亏色冲突。
- 规范写明：插画 / 图标只用品牌双色；任何涨跌数字、收益曲线严格走独立盈亏色板。

## 七、互动玩法：找出你的投资贝类（进化之旅）

- 两轴评分（对齐经典风险容忍维度）：
  - 轴 A 交易活跃度：频繁看盘 / 择时 ↔ 买了不看 / 长期。
  - 轴 B 回撤容忍：能忍大回撤 ↔ 绝不容忍回撤。
- 输出：一个对应生物插画 + 建议。
- **框架修订**：不做"贴标签 / 定性"，做"进化之旅"——呈现"你当前处于哪个贝壳阶段，下一步可进化成哪种"，aspirational 不羞辱（尤其船蛸新手）。
- **免责**：结果页标注"仅为趣味画像，不构成投资建议"。
- 落位：诚实区 / 新手引导；**非阻塞、可选**，不挡核心记账路径。
