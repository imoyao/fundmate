# /about 品牌故事页 · 方案评估与建议

> 本文针对「深海五层沉浸式电影」与「轻量级沉浸排版」两种 `/about` 方案，结合
> `brand-v1.6.md` 的硬性约束做评估，并给出推荐落地框架。
> 结论先行：**以方案二（轻量排版）为骨架，吸收方案一「下潜式阅读动线」的意图，
> 但用浅色令牌与珊瑚红块承载节奏，不引入任何暗色载体。**

---

## 0. 评估结论（一句话）

**推荐方案二作主体框架，并补齐品牌标准已定义的四项（data-reveal 滚动揭示、
珊瑚红大面积色块、Inter 字体、超椭圆 SVG 容器）。方案一的核心问题在于
「深海黑/深水蓝」暗色基底，这与 `brand-v1.6` 的浅色优先原则正面冲突，
属于不可接受的范围偏离，不应采用。**

理由不是"复杂与否"，而是"是否符合品牌标准"——方案一的叙事意图（镜头下潜、
逐层深入）是好的，但它的视觉载体（暗色）在标准里被明确禁止；方案的二视觉载体
（浅色）正确，只是缺了标准要求的几个工程件。

## 1. 维度对照表

| 评估维度 | 方案一（深海电影） | 方案二（轻量排版） | 品牌标准要求 | 胜方 |
|:---|:---|:---|:---|:---|
| 底色载体 | 深水蓝/深海黑渐变、#1A1A1A、#2C3E50 深色块 | 暖奶油 `#FDFBF7` 全篇 | §3.3 浅色优先、不提供暗色切换 | **方案二** |

| 用色大胆（视觉重心） | 深色为主，珊瑚红仅作局部卡片 | 珊瑚红作文字高亮/局部块 | §3.4 珊瑚红应以**大面积色块**承担重心 | 待补齐（见 §4） |
| 图标 | emoji / 拟物插画混用 | 1–2 个鹦鹉螺 SVG 线框 | §9 禁 emoji、SVG、超椭圆容器、珊瑚红描边 | 方案二（需约束） |

| 字体 | 未声明 | 未声明 | §4 Inter 体系（非 Noto） | 均需修正 |
| 维护成本 | 高（滚动监听、明暗切换、多背景） | 低（纯排版） | §11 防弱实现、低复杂度优先 | **方案二** |
| 母题契合（潮间带/下潜） | 高（暗色深海意象强） | 中（靠文案+留白暗示） | §1 母题为潮间带/潮汐，非深海黑 | 方案一意图更贴，但载体违规 |

**结论**：方案二在 6 个硬约束上达标或仅需补齐工程件；方案一无解地违反 §3.3 与 §3.1。

## 2. 方案一的问题（硬约束冲突，不可采纳）

### 2.1 违反 §3.3「主站浅色优先，不提供暗色切换」
> 品牌以暖奶油 `#FDFBF7` + 珊瑚红构建，浅色是原生载体；落地页属"滚动即走"型，
> 无长会话切换诉求……暗色策略仅适用于工具站。

方案一的「深水蓝/深海黑渐变铺底」「接近 `#1A1A1A` 或 `#2C3E50` 的幽暗背景」
本质是为主站引入暗色载体，与标准直接相悖。这不是审美取舍，是范围边界。

### 2.2 违反 §3.1「不新增背景令牌」
> 浅暖底 `#F5F0EB` 是全站唯一次级背景令牌……不再为营销页新增独立背景令牌。

方案一引入的深蓝、深海黑、磨砂玻璃底等均不在色板内，属擅自扩展暗色系。

### 2.3 动效实现容易踩 §6 的坑
- 「镜头下潜」明暗切换动画若落地，必须满足 §6.4 可见度下限（位移 ≥16px、opacity
  有明显变化）与 §6.7 `prefers-reduced-motion` 降级；暗→亮整屏切换在无障碍审查中
  极难达标（易触发 WCAG 2.3.3）。
- 滚动监听切换背景是一种"脆弱动效"，与 §6.5「被动触发优于自动循环、离开不回放」
  的精神也未必契合，维护成本高。

### 2.4 "拼贴感"并未真正解决
方案一靠 5–6 个强对比背景块分割，反而更易显"积木感"——因为每个块的颜色/明度
跳跃太大。方案二的"留白节奏"才是消解拼贴感的更稳妥手法。

## 3. 方案二的优点与待补齐项

### 3.1 优点（已契合标准）
- 浅色基底 `#FDFBF7` ✓ §3.3
- 仅用既有令牌 `#F5F0EB` 作呼吸色块 ✓ §3.1
- 珊瑚红 `#E34F38` 作文字高亮 ✓ §3.4（部分）
- 1–2 个 SVG 极简图标（鹦鹉螺轮廓）的方向 ✓ §9
- 纯排版、低维护 ✓ §11

### 3.2 必须补齐的四项（否则不算对齐标准）
1. **data-reveal 滚动揭示**：方案二说"无动效"，但标准 §6.5 要求内容区进入视口
   触发一次 fade+上移（`translateY(20px)→0`，`opacity 0→1`，缓动
   `cubic-bezier(.19,1,.22,1)`）。这正是"逐段下潜"质感的正确实现方式——
   **用标准滚动揭示替代 JS 明暗切换**，既保留下潜叙事，又合规。
2. **珊瑚红大面积色块**：§3.4 明确要求珊瑚红以大面积色块承担视觉重心。方案二
   偏"文字高亮"而缺体量。建议在「觉醒对话」或「诚实承诺」处用一块珊瑚红 `#E34F38`
   实心区（白字），替代方案一想要的"海底热泉庄严感"——但用珊瑚红而非深海黑。
3. **Inter 字体体系**：§4 已定 Inter 栈，about 页直接采用，不要沿用草稿的 Noto。
4. **超椭圆 SVG 容器**：§5/§9 要求插画背景底与图形容器用 n=3 超椭圆，而非正圆/
   直角。鹦鹉螺线框图放入超椭圆 `#F5F0EB` 底容器中。

## 4. 推荐落地框架（融合版 · 对齐 brand-v1.6）

叙事线索保留方案一的「下潜」意图，但视觉用**浅色渐进**承载：
`暖奶油 → 浅暖色块(#F5F0EB) → 珊瑚红实心块 → 暖奶油收束`，
靠留白节奏 + data-reveal 逐段淡入，模拟"读完一层再沉一层"。

| 段 | 内容锚点 | 视觉令牌（均来自标准） | 动效 |
|:---|:---|:---|:---|
| 开篇·镜头下潜 | 阳光/下潜/光线被吞没（原文前两段） | 暖奶油 `#FDFBF7` 大留白，中暖灰 `#6B655C` 细字（14px，行高 2.0） | data-reveal |
| 透光层·深海与鹦鹉螺 | "海面之下 800 米""鹦鹉螺栖息幽暗" | `#F5F0EB` 浅暖呼吸块（超椭圆容器），32px/600 深色引文 | data-reveal + 鹦鹉螺 SVG（珊瑚红描边） |
| 洋流层·哲学思辨 | "靠什么换钱""创业 vs 投资" | **珊瑚红 `#E34F38` 大面积实心块 + 白字**，逐句成行（宣言感） | data-reveal |
| 深水区·觉醒对话 | "八年折腾…""总算不是裸泳了" | 柔白 `#FFFFFF` 卡片 + 极细描边，大左右边距（证据感） | data-reveal |
| 海床·诚实承诺 | 不荐股不跟单 / 数据主权 | 暖奶油 `#FDFBF7`，珊瑚红文字高亮，顶部细横线 | data-reveal |
| 收尾·品牌韵脚 + CTA | "潮有涨落…""备贝多" | 暖奶油大留白，珊瑚红胶囊 CTA（9999px，≥48px 触控） | data-reveal |

### 4.1 海洋生物生态装饰条（吸收方案一 06 的意图）
- 保留"你的投资性格，是哪种海洋生物？"纯装饰横条，但**背景用 `#F5F0EB` 而非
  深水蓝**，用珊瑚红/暖灰线条勾勒 鹦鹉螺·角贝·扇贝·石鳖 四枚 SVG（超椭圆容器，
  §9）。
- 底配一行极小字："我们不做潮水的预测者，只做如实记录每一道壳纹的刻度尺。"
- 此条为纯视觉呼吸，不交互、不点开。

### 4.2 明确不做的
- 不引入任何深色背景（#1A1A1A / 深蓝 / 深海黑）→ 守 §3.3、§3.1。
- 不用 emoji 作图标 → 守 §9。
- 不做 JS 滚动明暗切换 → 改用标准 data-reveal，守 §6。
- 不照搬 monopo 暗底虹彩液体动效 → 如要用液体感，按 §6.6 品牌重着色（珊瑚→浅珊瑚→浅水绿）。

## 5. 待评审拍板的开放问题

1. **珊瑚红实心块放在哪一段**？建议「洋流层·哲学思辨」（叙事张力最强、且天然
   需要"庄严/压迫"感）。如你更想强调觉醒，可改放「深水区」。
2. **生态装饰条是否要**？它增加设计感但占篇幅；若只想最克制，可只保留鹦鹉螺
   一枚 SVG，省略四生物横条。
3. **about 页是否复用 landing 的构建管线**（YML 文案源 + build-landing.mjs）？
   建议复用同一套，保持双页维护一致。
4. **文件路径**：独立页 `/about`，对应产物 `about.html`，导航栏「品牌故事」链接至此
   （§8 已规划独立页，非落地页锚点）。
