## 1. 品牌定位与核心意象

- **母题：深海与鹦鹉螺（The Deep Sea & Nautilus）**。市场表面的繁华就像海面之上的狂风骤雨，而真实的资产价值藏在看不见的暗流深处。鹦鹉螺通过调节气室来丈量深海坐标，隐喻投资者通过精确计算来掌控复利刻度。品牌气质：温暖（珊瑚红）、精确（气室）、可信（不盲从）。
- **核心符号：鹦鹉螺对数螺线（Nautilus Logarithmic Spiral）**。螺线的等角扩张天然隐喻"复利"——每一圈都比前一圈以相同比例放大。Logo 与装饰图形统一以对数螺线为母题。
- **四件品牌辨识度锚点（不可稀释）**：① 珊瑚红 `#E34F38`；② 暖奶油 `#FDFBF7`；③ 鹦鹉螺螺线/深海刻度的意象；④ 涟漪/呼吸的有机动律。

### 1.1 设计哲学：Alive（生命感）

- **主张**：科技产品易陷于冷硬、直角、机械感；"Alive" 用有机曲线把"科技"与"生命"缝合——品牌视觉应让人感到"在生长、在呼吸"，而非"被计算"。
- **形态几何**：所有**容器级外轮廓**（Logo 背景、图形母题框、插画底色、色块）由直角方形统一改为 **n=3 超椭圆**：`|x/a|^3 + |y/a|^3 = 1`。其曲线无直线段，介于圆与方之间，圆润中带张力，即"生命流动感"的几何来源。
- **落地边界**：超椭圆用于"容器/底"，不替代螺线描边与珊瑚红主色；圆角令牌（`16px`/`9999px`）仍用于卡片与按钮，二者并存不悖。

### 1.2 品牌钩子与核心哲学隐喻（v1.7 新增）

> **品牌钩子（30 字以内）**
> 潮水不可控，但壳的刻度由你掌控。

> **核心哲学隐喻（约 100 字）**
> 鹦鹉螺从不预测洋流。它做一件更聪明的事——主动调节壳内三十余间气室的海水压差。哪怕海面风暴再大，它靠的也只是气室间毫厘的微调，来丈量自己在深海里的坐标。
>
> 投资亦是如此：我们无法控制市场的狂风骤雨，但可以精确计算出资产在这个波动区间里的真实刻度。多多贝，就是帮你测量"壳"上每一道新刻度的标尺。

**危险色使用约束**（避免与品牌红混淆）：① 仅用于删除/错误/破坏性操作，不与品牌红同处一个组件的相邻位置；② 与背景文本对比度 ≥ 4.5:1；③ 禁止用品牌红 `#E34F38` 表示"错误/删除"语义。

> **盈亏语义独立原则（v1.7 补强 · 对齐插画规范 v0.1 §六）**：珊瑚红是品牌色，**不得**承担涨跌盈亏语义。A 股"红涨绿跌"，任何收益数字、盈亏曲线、涨跌标记一律走**独立盈亏色板**（如 `--color-rise` / `--color-fall`），不得用品牌珊瑚红充当"涨=红"的认知。品牌红与盈亏红在视觉上必须可区分，避免"品牌红=永远涨"的误读。

### 3.2 浓度映射

"浓度"指同一品牌色在不同用途下的明度/饱和度档位。开发阶段直接映射 design.md 色阶，无需自创取值：

| 用途 | 浓度 | 取值 | design.md 令牌 |
|:---|:---|:---|:---|
| 主色 / CTA / 关键数字 / 大面积实心块 | 100% | `#E34F38` | `--brand-700` / `--color-rise` |
| 次级填充 / 浅色块 / 图表辅助 | 50–60% | `#FABDB0`–`#FDD9D0` | `--brand-400`–`--brand-300` |
| 极淡底色 / 氛围晕染 / 呼吸涟漪 | ~30% | `#FEEDE8`–`#FFF5F3` | `--brand-200`–`--brand-100` |

### 3.3 主站用色策略：浅色优先，但用色大胆

主站画布保持浅色（暖奶油 `#FDFBF7`），但**用色要自信、有体量，拒绝"性冷淡风"**：

- 珊瑚红 `#E34F38` 不应只出现在按钮与描边——应以**大面积色块**承担视觉重心（如 `/about` 页面中的「洋流层·哲学思辨」板块）。
- 浅水绿 `#7BC49A` 作副色，用于强调块、数据标签、液体动效第二色相，制造暖—冷对比的呼吸感。
- 浓度映射（§3.2）中的 30% 淡色仅用于极轻氛围晕染；主站主体应使用 100%（`#E34F38`）与 50–60% 档位建立明确色彩体量。
- 液体流动动效（§6.6）可用饱和珊瑚场而非淡 tint，强化品牌记忆。

> 平衡：大胆的是**用色面积与饱和度**，不是信息密度或煽动性文案。数据主权边界（不荐股、不跟单）的克制态度保持不变。

### 3.4 暗色模式

主站（营销/落地页）为**浅色优先，不提供暗色切换**：品牌以暖奶油 `#FDFBF7` + 珊瑚红构建，浅色是原生载体；落地页属"滚动即走"型，无长会话切换诉求，且参考站 monopo 亦为浅色。暗色策略**仅适用于工具站**（`frontend/design.md` / `frontend/design.dark.md`，经 `data-theme` 驱动，含系统偏好被动适配）。主站若未来需被动适配系统暗色，另行评估，不纳入 v1.7 范围。

## 6. 动效策略（规范级）

> **v1.4/1.5 复盘**：动效章此前为"描述性"，导致 AI/前端自取极保守值——涟漪 `opacity 0.05→0.15` 肉眼近乎不可见、滚动动效退化为无意义代码。本版改为**强制工程规范**：所有动效须达"可感知阈值"，且必须可降级。

### 6.1 设计原则

1. **有机而非机械**：动律取自潮间带——呼吸、涟漪、缓慢扩张，拒绝生硬弹跳。
2. **耐心缓动**：统一使用 `cubic-bezier(0.19, 1, 0.22, 1)`（expo-out 变体），起步柔、收尾缓，与主站"慢而可信"气质一致。
3. **可感知优先**：任何"装饰性"动效的可见度不得低到看不见（见 §6.4 下限）。
4. **被动触发优于自动循环**：内容区动效默认由滚动进入视口触发；仅品牌区（Hero）允许低强度自动呼吸。

### 6.2 缓动与时长基准

| 动效类型 | 缓动 | 时长 | 说明 |
|:---|:---|:---|:---|
| 品牌呼吸（Logo/涟漪） | `cubic-bezier(0.19,1,0.22,1)` | 6–8s | 无限循环，`alternate` |
| 滚动揭示（fade+位移） | `cubic-bezier(0.19,1,0.22,1)` | 0.6–0.9s | 进入视口触发一次 |
| 悬停反馈（按钮/卡片） | `ease-out` | 0.2–0.3s | 仅颜色/阴影/轻微位移 |
| 液体流动（goo 融合） | `cubic-bezier(0.19,1,0.22,1)` | 14–22s | 多 blob 错相位漂移 |

### 6.3 品牌区自动呼吸（Hero）

- **涟漪**：同心圆 2–3 圈，错相位扩张；`opacity` 下限 **0.12**、上限 **0.22**（严禁低于 0.1）。描边用 `--brand-700` 或 `--brand-400`。
- **Logo 呼吸**：`scale(1) → scale(1.03)`（幅度小于 1.05 以免喧宾夺主），6s 循环。
- 呼吸是"氛围"而非"信息"，强度克制。

### 6.4 可见度下限（硬约束）

| 动效 | 最低可感知标准 |
|:---|:---|
| 呼吸/涟漪透明度 | `opacity ≥ 0.12`（峰值 ≥ 0.20） |
| 滚动揭示位移 | `translateY(16–24px) → 0` 且 `opacity 0 → 1` |
| 悬停态反馈 | 颜色/阴影变化须肉眼可辨（对比差 ≥ 1.5:1） |

> 违反下限（如 `opacity 0.05`、`scale 1→1.02` 不可见位移）视为未达标，需在评审退回。

### 6.5 滚动揭示模式（内容区标准实现）

内容区动效统一用 IntersectionObserver，**进入视口触发一次 fade+上移**，离开不回放：

```js
const observer = new IntersectionObserver((entries) => {
  for (const e of entries) {
    if (e.isIntersecting) {
      e.target.classList.add('in-view');   // 触发一次后停止观察
      observer.unobserve(e.target);
    }
  }
}, { threshold: 0.15, rootMargin: '0px 0px -10% 0px' });

document.querySelectorAll('[data-reveal]').forEach(el => observer.observe(el));
```

```css
[data-reveal] { opacity: 0; transform: translateY(20px);
  transition: opacity .7s cubic-bezier(.19,1,.22,1), transform .7s cubic-bezier(.19,1,.22,1); }
[data-reveal].in-view { opacity: 1; transform: none; }
```

> **反例（v1.4 实际产出）**：某实现用 IntersectionObserver 仅 pause/resume Hero 涟漪——涟漪本就在首屏视口内，该代码无任何可见效果，属无效动效，禁止。

### 6.6 液体流动动效（可选 Hero 增强 · 借用 monopo 液体感）

可借用 monopo saigon 的"乳液流动"液体感，但**必须品牌重着色**：以珊瑚红→暖珊瑚浅调→浅水绿（`#E34F38 → #F2A38E → #7BC49A`）替代其薄荷/橙/牛血红虹彩，保留四锚点。

技术：SVG `feGaussianBlur` + `feColorMatrix`（拉高 alpha 对比）的 goo 融球滤镜，让多个色块像乳液般融合；多 blob 错相位慢漂（14–22s）。参考实现见仓库根目录 `demo-liquid.html`（已用品牌色验证，随本版交付）。

> **交付注记（2026-08-08）**：`demo-liquid.html` 在当前工作区未检出；本文件以"品牌色重着色原则"为准，若该参考实现需随版交付，请确认其落盘位置（不影响 §6.6 规范本身）。

### 6.7 无障碍适配（硬约束）

品牌区自动呼吸动效在 `prefers-reduced-motion: reduce` 下**必须降级为静态**，否则违反 WCAG 2.3.3（动画无障碍）：

```css
@media (prefers-reduced-motion: reduce) {
  .ripple, .logo-breathe, .blob { animation: none !important; }
  [data-reveal] { opacity: 1; transform: none; transition: none; }
}
```

内容区交互动效（滚动触发、悬停）不受影响，但须确保触发条件在降级后仍可正常操作（即内容默认可见，不依赖动画显示）。

## 8. 品牌故事与数据主权（v1.7 最新完整版）

> **建议位置（v1.7 拍板）**：完整品牌故事正文为**唯一文案源**，由独立页 `/about`（`about.html`）引用渲染。
> 落地页**不再保留** `#story` 锚点区块——改为一段**简短引流文案 + 入口链接至 `/about`**（见 §10 对齐清单），既保留情感铺垫、又不抢转化主线，形成"落地页引流 → 独立页承载完整叙事"的闭环。

**为什么做多多贝？**

阳光穿过透明的浅海，照亮了海底的珊瑚森林。枝杈在水流中缓缓摇摆，染出一片温暖而鲜活的珊瑚红。

镜头追随着这片光，开始从海面垂直下潜——光线被层层海水吞没，蓝色由浅及深，喧嚣逐渐归于沉寂。直到海面之下 800 米，这里是另一片天地：没有风，没有浪，只有无声涌动的暗流和足以碾碎金属的庞大水压。

鹦鹉螺，就栖息在这片永恒的幽暗之中。

它从不对抗深海的水压，而是用另一种方式回应这片环境：微调壳内三十余间气室的海水压差，在漆黑中保持着精准的平衡。每一次气室的排出与注入，都精确到毫厘。日复一日，每一道洋流的强弱起伏，都化作它壳上新生的纹路。

我们每一个置身市场的人，何尝不是潜入自己的深海。市场的每一次脉冲，就是海面以上的狂风骤雨；而真实的资产价值，始终藏在水面之下的暗流中。账户里的浮盈浮亏，不过是海面上偶尔翻起的浪花。

很多人认为投资就是追着浪头跑，但我逐渐想明白了一件事：财富增长的上限，永远取决于你靠什么换钱。

单纯出卖时间，天花板抬眼就能看到。真正能触到无上限的，无非两条路：创业或者投资。创业是一场高度脆弱的赌局，它需要把所有筹码押在风口上，哪怕你每一步都没做错，只要对手比你做得更好、实力比你更强，你就可能随时出局。

而投资呢？它可以没那么暴烈，而且给了普通个体一种更平等的可能——你不需要团队，不需要抢风口，哪怕全世界有一万个人比你聪明，也丝毫不影响你在自己的账户里取得满意的回报。

对大多数渴望财富的人来说，投资，是避不开的一步。

于是我开始自问：那我到底该怎么做，才算是"有备无患"？

答案很朴素——别急着预测下一个浪头，先把潮水退去时自己到底站在哪算清楚。

做多多贝的起点，是我自己首先算不清自己的账了。手里好几个券商和基金账户，满屏浮盈。涨潮时觉得自己是天才，退潮时才发现连资金进出都是一笔糊涂账。

于是我写了个极简的脚本。不直连账户，只导入交易记录 CSV，输出一个最直接的数字：XIRR。它不跟市场脉搏跳动，只告诉你一个坐标——你真实的复利轨迹，到底在哪。

后来我把它分享给一位朋友。他跟投了一个号称"十年十倍"的投资组合。

结果数据拉出来，他盯着那个数字沉默了许久，然后叹了口气：

"八年折腾，收益还不如一笔三年期定期存款。原来一直都在闭着眼瞎投。"

但他停顿后补了一句：
"好在，今天总算不是裸泳了。"

那一刻我意识到，对大多数人来说，真正需要的不是能预知市场的"神技"，而是看清市场真相后，那种不会再被潮水裹挟的定力。

多多贝，想成为帮你掌控那间"气室刻度"的标尺。

我们不荐股、不跟单。所有数据由你手动录入或交割单导入，主权归你，随时可一键导出带走。我们不做带你追浪的弄潮儿，只用数据的事实说话，做一把诚实的度尺。潮水涨落千年，只要你在潮水涌来的时候调控好自己气室的压力，就能一圈圈长出属于自己的生长刻度。

**潮有涨落，壳有深浅。算得清，才无患。**
**多多贝，贝倍多——复利生长，越理越多。**

> **数据主权边界**（不变）：不荐股、不跟单、不预测市场；不自动抓取；数据可导出、不用于营销。

## 11. 给前端 / AI 的实现指引（防弱实现）

为避免 v1.4 再次出现"动效少且不可见"，落地时遵守：

1. 动效先用本文件 §6 的代码片段，不另起炉灶；缓动固定 `cubic-bezier(0.19,1,0.22,1)`。
2. 任何装饰动效自测可见度，低于 §6.4 下限即不合格。
3. 滚动揭示必须真正改变 `opacity` 与 `translateY`（参考 §6.5），不得只 pause/resume 已有动画。
4. 图标全量替换为 SVG，grep 确认无 emoji 残留。
5. 交付前用 `@media (prefers-reduced-motion: reduce)` 实测降级为静态。
6. **关于页面开发**：复用 `landing` 的 YML 构建管线（`build-landing.mjs`），输出 `/about.html`。避免维护两份独立的 HTML 代码，杜绝文档与实现漂移。
7. 盈亏语义走独立色板，品牌珊瑚红不得承担涨跌（§3.1 盈亏独立原则）。
8. **Logo 接入**：直接使用 `logo-delivery/` 实际交付文件（§5 交付文件索引），**不要**按早期"favicon.svg / apple-touch-icon.png"等命名臆造；favicon 用 `favicon.ico`（Form 4）或 `favicon_form1r.ico`（Form 1R）。详见 `LOGO_DELIVERY.md` 第九章「前端对接注意事项」（viewBox / 禁用 symbol+use / 多实例 id 隔离）。
