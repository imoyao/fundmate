      这次重设计了什么

      数据全部取自本地真实库（远足 / ZH012926，净值 2263 个交易日）。版式只消费 colors.css 与 dark.scss 的语义令牌，明暗双主题同源。

      01 结论先上首屏

      原来「净值 / 日涨跌」是资料网格里第 7、8 格，收益与回撤要到下一张卡才出现。新首屏把它们收进一条主数字 + 四格 KPI：净值 2.7550、近一年 +1.99%、成立以来 +175.50%、最大回撤 32.96%、夏普 0.553，一屏答完「它是什么、现在怎么样、代价多大」。

      02 身份与行情分家

      原 AdvisorFacts 八格里混着身份（平台 / 机构）、属性（风险 / 类型 / 成立）与行情（最新净值 / 日涨跌）。行情提到首屏，属性下沉到 §06 档案，身份压成一行 meta。

      03 收益改成可比条形

      六个区间原来只是六个同权重数字。近端四档（1M/3M/6M/1Y）放进同一 ±20% 刻度做双向条形，零轴在中间；成立以来与近三年单独做大数字，不再与「近 1 月 −7.67%」挤在一行抢注意力。

      04 成分基金回归表格

      十二只成分原来是三列行栈（名称贴左、数字钉右），扫不出集中度。现在是真表格：权重列带条内条、按占比排序、已持有的加圆点标记，表头直接给「前三大 45.59%」。

      05 账户对照改成方向对比

      原来「我持有 · 组合里没有」只给了一个 115 只的清单——数量本身不说明问题。现在按基金风格暴露（大盘 / 中盘 / 小盘 / 港股 / 固收）把两边都折成占比，同一刻度上画成对条，差值 ≥5pp 才点红；提示条只点最不一致的两档。组合外持仓明细折叠在下面，要查具体哪只再展开。

      06 调仓改成时间轴

      原来每次调仓的行与 100+ 字理由平铺，二十次调仓把页面拉到七千像素。现在按日聚合成时间轴：日期轴点 + 调入/调出计数 chip + 两栏「前 → 后」明细，理由合并成一段、默认两行截断，更早的十六次收进「查看更早」。

      07 数据可信度收口

      来源与口径原来散在每张卡脚注、各写各的。现在只在 §06 出现一次；缺值统一「—」+ 弱色，不再与 0 混淆。

      规格摘要

      栅格：主列 + 264px 侧栏（只放速览，<1080 收起）；页内锚点在页头右上角，点开是六项下拉，滚动时高亮当前区块。内容宽 1400px，区块间距 32px，卡内 24px，表格行 43px。字阶走令牌（24 / 20 / 16 / 14 / 13 / 12），数字 tabular-nums。红涨绿跌 + ↑↓ 双编码，颜色不是唯一载体。
