# 多多贝 · 首页欢迎语位置设计规范 v1.2

本文档规范「多多贝」登录后仪表盘顶部欢迎语位置的内容、状态与交互逻辑。
此位置位于页面左上角，总资产卡片正上方，是用户登录后第一眼看到的内容区域。

设计原则：此位置不做数据复读机，不重复展示页面其他区域已有的数据。
底部卡片已展示：总资产、投资以来收益、XIRR。
此位置应展示：底部没有、用户能控制、无情绪压力的数据。

---

## 一、核心数据

唯一展示的数据是：已记账天数（记录用户自第一笔交易录入至今的自然日天数）。

- 算法：首笔交易录入日 → 当前日期的自然日差值
- 断更仍累计，本质是「累计天数」而非「连续无中断天数」
- 文案表述为「你已记账 N 天」

---

## 二、状态定义

### 状态一：空状态（无任何持仓/交易数据）

```
把涨跌交给市场，用复利丈量自己 🌊
[开始记账]
```

- 展示品牌定调语，不展示天数或资产数据
- 右侧按钮为「开始记账」，点击跳转至 `/asset/entry`
- 按钮样式：胶囊（`--radius-pill`），背景 `--brand-700`，白色文字
- 按钮交互状态：遵循 design.md 主按钮规范（hover → `--brand-800`、active → `--brand-900` + `translateY(1px)`、focus → `--focus-ring`、disabled → 50% 透明）

### 状态二：数据状态（有持仓/交易数据）

```
晚上好 👋 你已记账 132 天
把涨跌交给市场，用复利丈量自己
```

- 第一行：时段问候 + 已记账天数（数字加粗，`--color-rise` 高亮，等宽字体 + `tabular-nums`）
- 第二行：品牌定调语（`--text-small`，`--text-secondary`）
- 不展示总资产、收益率、盈亏数据（底部卡片已有）
- 右侧无独立按钮

### 状态三：有未读站内信时（与状态一/二叠加）

```
📬 你有 1 条未读消息 [查看]
把涨跌交给市场，用复利丈量自己
```

- 消息提示条叠加在顶部，品牌定调语作为副行继续保留
- 「查看」按钮复用 `lay-notice` 的未读跳转逻辑，不新建组件
- 右侧按钮逻辑见下文「右侧按钮逻辑矩阵」

### 右侧按钮逻辑矩阵

| 场景 | 右侧按钮 |
|------|----------|
| 空状态 + 无未读 | 「开始记账」 |
| 空状态 + 有未读 | 「开始记账」（消息条在顶部另含「查看」） |
| 数据状态 + 无未读 | 无 |
| 数据状态 + 有未读 | 无（「查看」在消息条内） |

## 三、时段问候语规则

| 时间段 | 问候语 |
|--------|--------|
| 05:00–12:00 | 早上好 |
| 12:00–18:00 | 下午好 |
| 18:00–22:00 | 晚上好 |
| 22:00–05:00 | 夜深了 |

`22:00–05:00` 为跨午夜区间，前端实现需拆为：`hour >= 22 || hour < 5`。

---

## 四、品牌定调语

固定文案：**把涨跌交给市场，用复利丈量自己。**

- 首次曝光于空状态，与品牌故事联动
- 数据状态时作为副标题持续存在，形成品牌记忆锚点
- 样式：`--text-small`，常规字重，`--text-secondary`

---

## 五、加载中状态

后端接口返回前，欢迎语区域展示：

```
把涨跌交给市场，用复利丈量自己 🌊
```

- 仅展示品牌定调语，天数位留空（不显示「已记账 0 天」，避免闪烁）
- 不显示任何按钮，避免误触
- 接口返回后瞬时切换至对应状态（空状态或数据状态）
- 加载失败：静默降级，保持品牌定调语展示，不阻塞页面

---

## 六、数据接口

新增轻量端点：`GET /api/profile/record-stats`

返回字段：

```json
{
  "first_entry_date": "2026-01-15",
  "record_days": 132
}
```

- 前端在 Welcome 页 `onMounted` 中拉取
- 不复用 `getSummary` / `getPortfolioXirr` 等现有接口

## 七、视觉规范（对齐 design.md 令牌）

| 元素 | 规格 | 令牌 |
|------|------|------|
| 主数据字号 | 24px，字重 500 | `--text-title` |
| 天数数字 | 等宽 + `tabular-nums`，加粗 | `--text-mono` + `font-variant-numeric: tabular-nums` |
| 天数高亮色 | 品牌色 | `--color-rise` |
| 品牌定调语字号 | 14px，常规 | `--text-small` |
| 品牌定调语颜色 | 中暖灰 | `--text-secondary` |
| 行距 | 1.5 / 1.43 | 对齐 design.md 字阶 |
| 两行间距 | 8px | `--space-2` |
| 整体边距 | 与下方资产卡片留 24px | `--space-standard` |
| 按钮圆角 | 9999px（欢迎语 CTA 例外） | `--radius-pill` |
| 按钮高度 | 40px | 对齐 design.md 主按钮 |
| 按钮内边距 | 8px 20px | 胶囊态微调 |

---

## 八、暗色模式

- 天数高亮走 `--color-rise`，由 `dark.scss` 自动覆盖为 `#d45a44`（提亮降饱和），无需特殊处理
- 组件内禁止写死暗色色值（参见 design.md 编码红线）

---

## 九、可访问性

- 问候语容器：`aria-live="polite"`，状态切换时读屏可感知
- 「开始记账」按钮：`aria-label="开始记账，进入持仓录入"`
- 颜色不作为唯一信息载体：天数高亮同时有加粗与字号层级区分
- 所有颜色变量变更须通过 axe-core / Lighthouse 对比度回归（design.md 强制约束）

---

## 十、与 design.md 的偏差声明

| 偏差点 | design.md 默认 | 本规范例外 | 理由 |
|--------|----------------|-----------|------|
| 欢迎语 CTA 圆角 | 主按钮 `--radius-sm`（6px） | `--radius-pill`（9999px）胶囊 | 首页首屏强调态，胶囊更具引导感；仅限此 CTA |
| 欢迎语主数据字号 | 无专用层级 | `--text-title`（24px/500） | 首屏第一眼锚点，需高于正文但低于总资产 hero（48px） |
