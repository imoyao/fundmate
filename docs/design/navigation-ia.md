# 导航信息架构（侧边栏 + 面包屑）

**定稿日期**：2026-10-30（侧边栏重组 2026-10-29 起，2026-10-30 补齐面包屑与文案）
**适用范围**：`frontend/src/router/modules/*.ts`、`SidebarBreadCrumb.vue`、`utils/breadcrumb.ts`
**守卫**：`router/__tests__/routeRankGuard.spec.ts`、`utils/__tests__/breadcrumb.spec.ts`、`scripts/check_router_links.mjs`

---

## 一、结论先行

导航按**财务动作**切一刀：**看结果 / 管配置 / 记事实 / 问助手**。四刀对应四个顶级，
除此之外不再有第二套分组逻辑。

| 顶级 | 财务动作 | 一句话判据 | 现有页面 |
|:--|:--|:--|:--|
| **资产概览** | 看结果 | 纯读，不写库、不下配置 | 投资概览 / 资产总览 / 持仓分析 / 投资复盘 |
| **资产管理** | 管配置 | 我在摆布这笔钱：目标、品类、观察、账户 | 四个分组（见下） |
| **记账中心** | 记事实 | 把已经发生的事落库，不产生判断 | 全面盘点 / 交易流水 / 分红股息 / 对账中心 |
| **智能助手** | 问助手 | 不落在账本结构里 | 账本精灵 |

「资产管理」内部再按**这一组装的是什么样的页面**分四组：

```
资产管理
├── 组合策略   一篮子的做法       投资组合 · 策略分析 · 定投计划
├── 实物资产   要手动登记估值     贵金属 · 房产
├── 我的关注   还没买、在挑、在盯  我的自选 · 特别关注 · 同类优选
└── 账户成员   记在哪个账户、算谁的 账户管理 · 家庭成员

隐藏下钻页（不进菜单）：/stocks 股票 · /funds 基金 · /asset/ledgers/:id · /asset/portfolios/:id
```

> 2026-10-30 二次修订：第一版四组叫「组合策略 / 品类持仓 / 观察名单 / 账户家庭」，
> 用户连着否掉后三个——「账户家庭是什么意思？说人话」「观察名单也不好」「品类持仓也不好」。
> 复盘发现**不是名字不好听，是成员装错了**：「品类持仓」里装着**同类优选**，而那是
> 「按你的持仓与自选做基金同类排序」的**筛选页**，页面副标题自己写着；名字与成员互相否定。
> 现按页面实际性质重排，并把 `/stocks`、`/funds` 从分组里提出来挂到直接子级
> （它们是「按产品类型看全部持仓」的下钻目标，挂哪个分组都是硬塞）。

## 二、为什么不再用「总览 + 资产管理」两套逻辑

重组前是 17 项平铺在两个顶级下，同一件事被劈开：

- **看**散在 5 处（投资概览、资产总览、持仓分析、复盘、同类优选）；
- **记**散在 4 处（全面盘点在概览、交易流水在概览、对账在资产、导入挂在「投资管理」目录）；
- **我的自选**（概览）与**特别关注**（资产）隔着两个顶级——同一件心事分住两栋楼。

根因不是条目多，而是**两个顶级用了两把不同的尺子**：「总览」按**使用频次**分组，
「资产管理」按**资产类型**分组。两把尺子交叉，必然有页面两边都像、只能靠 `rank: 3.5`
这类小数补位（小数补位本身即「已无序可插」的病征）。

## 三、为什么不按「四笔钱」分导航

`docs/design/si-bi-qian.md` 的四/五笔钱（活钱 / 稳健 / 长期 / 保险 / 博弈）是**资产配置**
维度，落在「配置目标」下拉与资产配置图里（`allocation` 字段）。它回答「这笔钱该放哪」，
不回答「我要去干哪件事」。若拿它做菜单，用户想记一笔账时得先判断这笔钱属于几笔钱——
把分类成本转嫁给最高频的动作。**配置维度与导航维度必须正交，不得互相复制。**

## 四、命名规则

1. **一律 4 个汉字**，唯一豁免是资产类别名词（「贵金属」「房产」）——扩写成 4 字会改变语义。
2. **名要副实**：目录里装什么就叫什么；名字读不懂时先查成员，再改字面。
   - 「投资管理」→「品类持仓」→「实物资产」：前两版都在暗示「这里涵盖全部投资」，
     实际只有贵金属/房产（股票/基金是隐藏路由）；且「品类」是电商品类思维，
     个人投资人嘴里不说这个词。
   - 「观察名单」→「我的关注」：「观察名单」是 watchlist 的直译，读者要在脑子里翻一次英文。
   - 「账户家庭」→「账户成员」：两个名词硬拼，拼完什么也没说。
   - 隐藏的基金筛选页「同类优选」从「实物资产」移到「我的关注」：它的输入是
     你的持仓与自选，产出是候选清单，属「在挑的」而非「已持有的」。
   - 「全面盘点」实质是**录入工作台**（页面自述「选择资产大类，快速录入或导入」），
     归「记」不归「看」。
   - 「复盘」→「投资复盘」：单说「复盘」不知复什么。
   - 「分红与股息」→「分红股息」、「对账工作台」→「对账中心」（页内 h1 与提示文案已同步）。
3. **隐藏路由只在两种情况下存在**：详情页（`/asset/ledgers/:id`）、
   被别处按 name 跳转的聚合下钻页（`/stocks`、`/funds`）。删前者丢面包屑锚点，
   删后者产生**静默死链**（`check_router_links.mjs` 会报）。

## 五、面包屑：为什么以前显示「总览 / 同类优选」

### 5.1 根因

`formatTwoStageRoutes` 把三级以上路由**拍平**挂到根 `/` 下，于是任意页面的
`route.matched` 永远是 `[Home, 当前页]`——父级信息在路由层就不存在了。
旧面包屑直接遍历 `matched`，所以无论点哪个入口，父级都只能是「总览」。
这不是「有时候不显示」，而是**父级恒错**。

### 5.2 修法

面包屑改为读**侧边栏菜单树**（`wholeMenus`），三级解析：

1. 精确命中当前 path；
2. 命中不到则取**最长前缀**（详情页 `/asset/ledgers/9` → 「账户管理」）；
3. 仍取不到返回空数组，调用方依次退到 `matched`、最后退到当前页标题——
   **宁可少一级，不允许空着**。

实现：`frontend/src/utils/breadcrumb.ts`（纯函数，可在 node 环境直测）。

### 5.3 为什么去掉了过渡动画

旧实现 `<TransitionGroup name="breadcrumb">` + `.breadcrumb-leave-active { position: absolute }`：
离场面包屑被绝对定位留在 DOM 里等 0.3s 过渡收尾，而 Vue 过渡靠 double-rAF 推进。
后台标签页或连续导航让两次过渡重叠时，leave 回调不执行，**旧面包屑永久留存**。

实测（Playwright 逐个点 19 个侧边栏叶子）：

| 版本 | 点「我的自选」读到的面包屑 | 19 项断言 |
|:--|:--|:--|
| 移除前 | `资产管理/品类持仓/同类优选/观察名单/我的自选` | 18 过 1 失 |
| 移除后 | `资产管理/观察名单/我的自选` | **19/19 全过** |

> 上表是 2026-10-29 的实测记录，分组名是当时那版（「品类持仓 / 观察名单」）。
> 按 2026-10-30 的二次修订，同一路径现在读作 `资产管理/我的关注/我的自选`。

面包屑是 2~3 个短词的位置指示，不需要动画。去掉后渲染与路由同步，
顺带解决了「后台标签页面包屑卡住」的老问题（此前用 `PlainGroup` 绕过）。

> 归因澄清：控制台里每次点侧边栏都有 2 条 `Cannot read properties of null (reading 'parentNode')`，
> 来自 `el-menu` 子菜单自身的展开/收拢，**与面包屑无关**——只用 `location.hash` 导航时 0 报错。
> 属既有问题，另案处理。

### 5.4 单子项分组必须设 `showParent`

`SidebarItem.hasOneShowingChild` 会把只有一个可见子项的父级**拍平**成菜单项
（父级名消失）；面包屑读菜单树、不拍平。于是出现「侧边栏 1 级 / 面包屑 2 级」：
「智能助手」在侧边栏消失，只留一个孤零零的顶级「账本精灵」。

解法是 `SidebarItem` 留的唯一逃生口：子项 `meta.showParent: true`
（`showingChildren[0]?.meta?.showParent` → 不拍平）。守卫已钉住此约束。

## 六、守卫清单（都得是机械判据）

| 断言 | 咬住什么 |
|:--|:--|
| 同级 `rank` 不得重复 | 排序键相等 → 次序靠数组先后兜底，改顺序就跳位置（#2152） |
| asset 直接子级 ∈[100,199]、全部孙级 ∈[200,299]、全树唯一 | 跨层撞键 |
| 顶级顺序 === 资产概览/资产管理/记账中心/智能助手 | 顶级回到「一个维度」 |
| 各分组的可见项逐个钉死 | 防止悄悄挪页面 |
| 菜单标题 4 字（豁免品类名词） | 视觉一致性 |
| 单子项分组必须 `showParent` | 侧边栏与面包屑层级一致 |
| `check_router_links.mjs` | 隐藏路由被删 → 按 name 跳转静默失败 |

## 七、反向约束（什么不许放进来）

- **读**的页面不许进「记账中心」，**配置**的页面不许进「资产概览」——否则又回到
  「两个顶级各装一半」。
- 录入流程页（对账单导入 / 导入持仓 / 手动记账 / 录入资产 / E账户对账）不进侧边栏，
  但**归属**「记账中心」，这样面包屑是「记账中心 / 对账单导入」而不是
  「资产管理 / 品类持仓 / 对账单导入」——定位与动作一致。
- 唯一子项的分组要么合并到别处，要么显式 `showParent`，不允许默认拍平后
  与面包屑打架。
- 不要给面包屑加回过渡动画；不要让面包屑依赖 `route.matched` 表达层级。
