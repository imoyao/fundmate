# 产品详情抽屉统一规范

> 适用范围：所有「点产品 → 弹抽屉看详情」的入口。当前三处——自选行速览、账户持仓明细、聚合产品详情。
> 组合详情页的成分基金列表同属本规范的阅读语汇（见 §7）。

## 1 为什么要统一

统一前三处抽屉各写一套：宽度 420 / 420 / 680，「查看详情」分别在头部 text 按钮（两处）与
底部普通按钮（一处），区块标题三套字号，数值层级从 32px 主数字到全 13px 并列都有。
用户看到的是「同一个动作，三个不同的界面」。

统一后只有**一个外壳**（`components/ProductDrawer`）、**一个出口位置**（sticky footer）、
**一套区块标题语言**。差异只允许存在于「抽屉内容」，不允许存在于「抽屉形状」。

## 2 骨架

```
#header   产品名（20/600）+ 识别信息行（代码 · 品类胶囊 · 平台/主理人）+ 关闭
#anchor   主数值（24/600）+ 副行（口径 / 涨跌 / 日期）        —— 唯一一个
区块 n     13/500 标题 + 内容（键值网格 / 列表 / 表格）
#footer   说明文案（13 左） + 「查看详情」（36px 描边按钮，右）  —— 唯一出口
```

- **只有两条线**：header 下沿、footer 上沿，均 1px `--border-light`。区块之间靠 32px 间距分节，不画线。
- **宽度 720px**（`--drawer-width: min(720px, 100vw)`）：三处共用一个值。
  一条 7 列的紧凑交易表内宽需求约 650px，720 − 48 恰好放下；<768 视口满宽。
- **泛化标题一律删除**（「速览」「持仓明细」）：产品名就是标题，抽屉标题栏再写一遍是双层标题。

## 3 头部

| 元素 | 规格 |
|---|---|
| 产品名 | `--text-heading`（20/600）、`--text-primary`、单行 ellipsis + `title` 全名；`<h2>` |
| 识别信息行 | `--text-label`（13/400）、`--text-tertiary-ink`；距名称 `--space-1`；顺序固定 |
| 代码 | `--font-mono` + `tabular-nums`，前缀 `#`；**组合类标的（portfolio / manager）不渲染** |
| 品类胶囊 | 外壳内建 `.pd-type`（`--bg-soft` + `--text-secondary` + `--radius-pill`）。**不复用** `AssetTypeBadge`——那是渠道类别徽章，颜色取自 `getLedgerColor(channel_category)`，装「混合型 / 投顾组合」会落到渠道默认色上（该组件另需收一个「品类胶囊」，见 §10） |
| 平台 / 主理人 | 缺失整段不渲染，不写 `—` |
| 关闭 | EP 默认按钮，视觉 28×28、命中 40×40（`::after inset:-6px`）、`aria-label="关闭"` |

## 4 锚点与数值层级

- 每个抽屉**恰好一个** 24/600 的锚点（`--text-num-hero`）：速览＝最新价（组合＝组合净值）、
  持仓明细＝持仓市值、聚合＝资产情况。
- 锚点副行：13/400 `--text-tertiary-ink`，承载涨跌幅 / 盈亏 / 口径日期。
- 次级数值：14/400–500 `--text-primary` + `tabular-nums`；标签 13/400 `--text-tertiary-ink`。
- **禁止出现第四种数字字号**：24（锚点）/ 14（键值）/ 13（标签）三档封顶。
- 键值网格：`repeat(2, minmax(0,1fr))`、gap `--space-compact`，**单元无边框无底色**，
  行间不用线（<480 降 1 列）。禁止「每格一张描边卡」——8 个描边矩形等于 8 个容器噪声。

## 5 区块标题与「查看详情」

- 区块标题：`--text-label`（13）/ 500 / `--text-secondary`，上 32 下 12，**不画分隔线**；
  右侧可放 13/400 辅助（如「共 12 条」）。**不复用** `SectionHeader`（其 16/600 属卡级语义，
  进抽屉会与 20/600 产品名层级倒挂），由 `ProductDrawer/DrawerSection.vue` 承载同一语言。
- 「查看详情」：**只在 footer**，右对齐 36px 描边按钮 + `ep:arrow-right`；
  左端同行 13/400 说明（可用时给收益、不可用时给原因）。
  不用实底主按钮——它是导航，不是提交；也不与关闭按钮同区（两个「离开」相邻易误触）。
- 品类无详情页时**不渲染按钮**，只留说明文案：灰按钮会制造「即将可用」的假期待，且读屏不解释原因。

## 6 内容取舍

### 6.1 删除（6 项）

| 项 | 位置 | 理由 |
|---|---|---|
| 「历史价格与成本曲线（数据依赖 P1-20 定时任务同步）」 | 持仓明细 | 空壳 + 把内部工单号写进界面，读成「图坏了」 |
| 「已加载全部交易记录」 | 持仓明细 | 运行时自证，不是内容 |
| 泛化标题「速览」「持仓明细」「聚合头部重复名」 | 三处 | 产品名已是标题 |
| header 内「查看详情」 | 持仓明细、聚合 | 出口只留 footer 一处 |
| 聚合抽屉的免责声明块 | 聚合 | 替以三处统一的 13px 单行（合规保留、降噪；`--text-label` 是现有最小字阶，不新造 12px） |
| 空态独立区块壳（暂无备注 / 暂无调仓记录占着带标题区块） | 速览 | 空态不占 32px 区块节奏 |

### 6.2 合并 / 降级

| 项 | 处理 |
|---|---|
| 速览「行情」区块 | 并进锚点（最新价 + 涨跌幅副行）——同一个问题不答两遍 |
| 速览「信息」（添加自选日 / 分组 / 标签） | 降为备注区末一行 13px 元信息；标签与分组是管理元数据，不是决策信息 |
| 持仓明细「持仓盈亏」+「盈亏率」两张卡 | 并成锚点副行（绝对值 + 比率是同一件事） |
| 持仓明细「持有份额/成本/净值/时长/年化」 | 8 卡 → 锚点 + 5 项键值网格（无卡） |
| 聚合四格（份额日期 + 净值日期） | 合并为一格「快照日期」+ 副注「份额与净值同期」——两格同取 `snapshot_date`，永远同值 |
| 聚合「基金管理人」带箭头 + `cursor:pointer` 但无点击 | 降为纯文本（假交互比没有更糟） |
| 「共 N 条」 | 并入「交易记录」标题右侧 |

### 6.3 保留

分渠道持仓明细（聚合独有解释力）、单渠道账户信息（补账唯一线索）、就地改总价 + 分摊预览
（全站唯一改数入口）、成分与调仓（组合抽屉独有）、备注可编辑、交易表（抽屉存在理由）、
XIRR「计算中…」（避免误读为算不出）。

## 7 组合详情页 · 成分基金

现状 `grid auto-fit minmax(180px,1fr)` + 每项 `space-between` + `overflow-wrap:anywhere`：
列数随容器阶跃、百分比对齐的是各列自身右缘、长名换行把行高撑歪——三者叠加必然参差。

统一为**行栈**：`minmax(0,1fr) 72px`，行高 32，名称单行 ellipsis + `title`，
百分比固定 72px 右对齐 + `tabular-nums`，行悬停 `--bg-soft`，按占比降序；
≥768 两列（每列内部仍是 `1fr/72px`），<768 单列；>12 只限高 384px 内层滚动 +「展开全部 N 只」。
未收录本地名录的成分给「未收录」灰标，不给链接。

## 8 验收判据

1. 三处抽屉根节点为同一组件产物：`[data-testid="product-drawer"]`，宽度 720（<768 满宽）。
2. 每抽屉 `[data-testid="num-anchor"]` 恰好 1 个，computed 24px/600。
3. header 下沿与 footer 上沿之外，抽屉内 1px 横线数 = 0。
4. 抽屉内 `button[disabled]` = 0；不存在品类时 footer 无按钮 + 有原因文案。
5. 抽屉全文不含 `/定时任务|P1-20|已加载全部交易记录/`。
6. 区块标题 computed 13px / `--text-secondary`。
7. 「查看详情」在 `[data-testid="drawer-footer"]` 内，且三个抽屉各仅 1 个。
8. 组合类标的抽屉不出现 `# 代码`。
9. 成分基金：任意两项百分比右缘差 ≤1px，行高 32±1，名称不换行。
10. 抽屉纵向无横向溢出（交易表内部横滚除外）。

## 9 不做（避免范围蔓延）

`TransactionTable` 列定义与 compact 契约、XIRR 取数链路与 null 语义、分摊算法
（整数分四舍五入 + 尾差归属）、`resolveDetailPath` 品类白名单、聚合取数分页、
`after_ratio` 口径、`--` / `—` 的全站统一（另开卡）。

## 10 已知限制

- 聚合分组只有 `symbol`、没有 `asset_type`，故该抽屉无法判断组合类标的（该端点为基金聚合，
  代码即基金代码，暂无影响）；持仓抽屉与速览抽屉已按 `asset_type` 隐藏组合代码。
- 表格行仍不可 Tab 聚焦：关闭抽屉后焦点归还到打开前的元素（`opener` 仍在 DOM 时），
  行级 `tabindex` / `aria-haspopup` 另开卡。
- 品类胶囊暂由外壳内建（`.pd-type`），与 `AssetTypeBadge`（渠道类别色）并存，
  待设计系统补一个真正的「品类胶囊」后收编。
