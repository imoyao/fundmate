## 功能项
1. 用户可以选择第三方登录或者邮箱注册：
    1. 如果使用第三方登录，则需要提示用户绑定邮箱
    2. 如果使用邮箱注册，则需要加延时，避免骚扰用户。同时用户登录之后提示用户激活邮箱，用户激活设置有效期，避免过期泄露
2. 通知用户信息功能实现，后端可以自定义发送信息给前端
