### 需求文档：记账功能增强 — 简记、全面盘点与数据去重

**依赖**：`SPEC.md v1.1` 中定义的 `transactions` 数据模型与 API 契约

---

### 1. 功能概述与定位

本次需求将记账功能拆分为两条互补路径，并内置完善的去重防呆机制，以满足不同场景下的用户效率与数据准确性需求。

| 功能         | 定位                     | 使用场景                           | 路由      |
| :----------- | :----------------------- | :--------------------------------- | :-------- |
| **简记**     | 高频、快速、轻量         | 日常随手记一笔买入或卖出           | 首页弹窗  |
| **全面盘点** | 低频、批量、完整、可校验、可对账 | 定期对账、首次迁移数据、复杂操作   | `/inventory` |

**核心原则**：
-   两条路径共享底层 `transactions` 表，保持数据一致性。
-   “简记”追求“30秒效率”，“全面盘点”追求“数据完整与准确”。
-   **任何导入操作都必须经过“去重检查”与“用户确认”两道关卡。**

---

### 2. 功能详述

#### 2.1 简记（首页弹窗优化）

**2.1.1 目标**
将用户最高频的“买入/卖出”操作，控制在最短路径内完成，避免页面跳转带来的注意力中断。

**2.1.2 交互入口**
-   **位置**：首页仪表盘右下角**悬浮操作按钮** 或顶部导航栏显眼位置的“+”图标。
-   **行为**：点击后弹出居中模态对话框。

**2.1.3 弹窗内容**
-   **类型切换**：顶部两个大标签，默认“买入”，可切换为“卖出”。
-   **表单字段（极简模式）**：
    -   **搜索选择器**：输入基金/股票名称或代码，带即时远程搜索建议。支持模糊匹配。
    -   **日期**：默认当天，可修改。
    -   **金额**：输入数字框。为方便用户，预留“份额”辅助换算的开关（可展开）。
    -   **费率**：预置通用默认值，可手动修改。
    -   **备注**：选填文本框，占位符文案“补充交易理由（选填）”。
    -   **保存按钮**：主按钮，点击后关闭弹窗，并刷新首页持仓。
-   **高级字段**：将非必填项（如“下午3点前”、“交易账户”、“对方账户”等）折叠在“更多选项”展开区域，保持默认界面清爽。

**2.1.4 范围决策（明确排除）**
-   **不包括**：分红、转股、拆合股、定投等复杂操作。
-   **原因**：这些操作参数多，需要校验和预览，不适合仅有一屏的弹窗。应在“全面盘点”中完成。

**2.1.5 引导**
-   弹窗底部设置低视觉权重的文字链接：“批量导入、分红转股、定投？去「全面盘点」>”。
-   **目的**：在不干扰核心操作的前提下，让用户知晓更强大功能的存在。

---

#### 2.2 全面盘点（独立页面 `/inventory`）

**2.2.1 目标**
为用户提供一个清晰、安全、向导式的批量数据处理中心，能覆盖所有复杂的记账操作、外部数据导入，以及关键的对账与去重功能。
##### 2.3.1 步骤条设计

采用水平步骤条，共 4 步：

-   第1步：选择导入方式
-   第2步：上传文件
-   第3步：预览、去重与修正
-   第4步：导入完成

##### 2.3.2 第1步：选择导入方式

以"卡片矩阵"形式呈现。每张卡片：图标 + 标题 + 一句说明文案。

**P1阶段可用的方式**：

1.  **CSV/Excel 文件**："使用我们提供的模板，或映射您自己的文件字段"
2.  **手动批量录入**："没有文件？在网页表格中逐行快速录入"
3.  **从持仓反推**："通过当前持仓，快速生成一笔初始买入记录"

**标记为规划中或 P2 的方式**：

4.  **券商交割单**（P2）：直接上传券商原始交割单文件
5.  **截图/照片**（P3，规划中）：上传交易截图智能识别。卡片置灰但不隐藏，标记"规划中"
6.  **API/JSON**（未来开放）

**对账模式开关**：卡片区上方开关"导入并对账"。

##### 2.3.3 第2步：上传文件

根据第1步所选方式，动态显示对应上传组件：

-   **文件导入**：拖拽/点击上传区，支持 `.csv`, `.xls`, `.xlsx`。下方提供标准模板下载链接
-   **手动批量**：直接跳转至第3步，给出空白可编辑在线表格

##### 2.3.4 第3步：预览、去重与修正

**去重机制（两层防护）**：

-   **第一层（UI智能标记）**：`symbol` + `date` + `type` + `quantity` + `price` 完全一致 → 黄色警告行，默认不勾选。Tooltip 显示库中重复记录。工具栏提供"一键取消全部重复行"
-   **第二层（后端校验）**：用户可选择"报错策略"或"静默跳过策略"

**对账模式（P1简化版）**：

-   差异行统一标记为"待确认"，由用户决策"新增"或"跳过"
-   P2 实现展开对比和覆盖功能

**其他功能**：

-   字段高亮（费率缺失、代码未匹配等）
-   表格内编辑
-   批量操作（批量设置费率等）
-   复杂操作入口（标记分红、转股等）

##### 2.3.5 第4步：导入完成

-   大号对勾图标 + "成功导入 X 笔交易"
-   失败明细（如有）
-   智能建议："您导入了股票交割单。是否现在去更新最新持仓市价？"

---

#### 3. 情感化设计与边界情况

-   **空状态处理**
    -   **简记弹窗**：若用户无持仓，在搜索框下显示“还没有持仓，先去「全面盘点」创建第一笔吧~”。
    -   **盘点页面**：首次进入`/inventory`时，展示一个欢迎横幅“欢迎使用全面盘点”，用图文引导用户选择一种导入方式开始。
-   **容错与安全**
    -   **导入预览**是最后防线，用户必须手动点击“确认导入”。
    -   **导入前自动备份**：系统应在确认导入前，自动备份本地数据库（`snapshot_YYYYMMDD_HHMMSS.db`），并提示用户“已在本地创建了导入前备份，如数据有误可恢复。”
    -   **定投**：从简记入口排除，但在盘点页的第3步，支持用户将一批周期性买入记录“识别为定投计划”，自动创建定投模板。
