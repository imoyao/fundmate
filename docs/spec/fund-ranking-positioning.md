# 同类优选页定位与自选页联动设计

> 日期：2026-10-17 · 关联：#167（同类风险榜上线）/ #2298（排序进表头）/ #2284（区间收益三列）
> 性质：**产品定位决策 + 联动设计**（先想清楚定位，再谈页面演化）

---

## 1. 结论（先给答案）

**「同类优选」（原「同类风险榜」，路由 `/asset/fund-ranking`）不是独立榜单产品，
而是自选页的「深度体检层」。**

一句话定位：

> 自选页回答「**我在看哪些基金**」；同类优选回答「**这些基金在同类里排第几、
> 风险收益比好不好**」。两者共享同一批基金（持仓 ∪ 自选），是同一产品的
> 「清单层」与「分析层」，不构成两个产品。

### 为什么不是「全市场榜单」

实证依据（`backend/app/services/sync/jobs/fund_risk_metrics_job.py`）：

- 快照目标池默认 = **持仓 ∪ 自选**（`_codes_from_user_scope`，与
  `orchestrator.resolve_targets()` 同源），无持仓无自选时**显式跳过**，
  绝不退化为全库 3 万只（#1403 的形态）；
- 榜单只在一个 `fund_type_id` 内排序（`list_by_metric` 必填），风险比跨类别不可比
  （债基波动 2% vs 股基 25%，夏普把波动当风险 ⇒ 债基系统性偏高）；
- 全市场同类榜是另一个形态（探市侧 + 净值回填扩容），已另立项，不在本页语义内。

因此页面名去掉「榜」字改为「同类优选」：「同类风险榜」听起来像天天基金式
全市场排行，与实际口径（持仓 ∪ 自选的同类体检）错位——这正是「机器生成感」
的来源。**「优选」表达优中选优，「同类」保留口径纪律，都不暗示全市场。**

## 2. 与自选页的联动设计

### 2.1 数据层：同源，不另立

| 层 | 页面 | 数据源 | 回答的问题 |
|---|---|---|---|
| 清单层 | 自选页（`/watchlist`） | watchlist API + positions | 看哪些、分组标签、实时估值 |
| 分析层 | 同类优选（`/asset/fund-ranking`） | `fund_risk_metrics` 快照（目标池 = 持仓 ∪ 自选） | 同类内风险收益比排第几 |

分析层的快照池就是清单层的并集——**用户不会在优选页看到一只自己从未接触过的基金**，
这保证了两页不割裂。

### 2.2 展示层：持仓/自选标记（2026-10-17 落地）

榜单行新增 `in_holdings` / `in_watchlist`（后端 `list_by_metric` 双域会话查询，
口径与快照目标池同源）：

- 持仓行：浅底纹常驻 + 名称旁「持仓」徽章（`--brand-100` 底软按钮档）；
- 自选行：「自选」徽章（`--bg-soft` 中性档）；
- 未登录 / 无状态：两个徽章都不渲染（诚实缺席，不占位）。

用户一眼能找到「我的那只」，并看到它在同类里的相对位置——这是本页与自选页
联动的**最小闭环**。

### 2.3 导航层：双向可达

- 基金名点击 → 基金详情页（已有，`/fund/<code>`）；
- 后续（P1）：行内「去自选页查看」入口 / 自选页行内「同类排名」入口，
  两页按 fund_code 互相跳转，形成闭环。

## 3. 页面 UI 优化清单（2026-10-17 落地）

来源：用户 UI/UX 评审意见 + 设计规范（`frontend/design.md`）校准。
原则：**去噪**（去掉独立筛选卡、常驻 i 图标、整行剔除提示）与
**聚焦**（围绕「我的持仓 vs 同类」强化对比）。

| # | 优化 | 落地形式 | 规范依据 |
|---|---|---|---|
| 1 | 筛选器收进表格 | 撤销独立「筛选」卡片，类型选择器移入表格卡片工具栏；`混合型（共 N 只）` | #1714「一层页头」原则 |
| 2 | 收益列红涨绿跌 | 年化收益 / 近1月 / 近3月 / 近1年：正 `--color-rise-ink`、负 `--color-fall-ink`，带 +/- 符号 | design.md 涨跌色应用；文字级 -ink 保 AA |
| 3 | 风险列不染红绿 | 夏普 / 卡玛 / UI / 波回比 / 最大回撤恒中性色 | 合规红线：不做好坏评价（本页纪律 3） |
| 4 | 数字对齐与精度 | 右对齐 + `tabular-nums` + 两位小数（已有，保留） | design.md 数字等宽对齐 |
| 5 | Sticky 列 | 「# 排名」+「基金」两列左冻结；表头吸顶 | design.md 冻结列与横向滚动规范 |
| 6 | 排序状态明确 | 激活列 = 底色 + 品牌色 + 加粗 + 实心方向箭头 | #2298 |
| 7 | 表头去噪 | 去掉常驻 `i` 图标；hover 表头弹 tooltip（含「越高/越低越好」）；底部「指标说明」折叠面板兜底 | 降噪 + 兜底 |
| 8 | 单位统一 | 表头去掉 `(%)`，工具栏右侧一行单位说明 | — |
| 9 | 剔除提示弱化 | 整行长条 → 工具栏 ⚠️ 胶囊（hover 气泡） | 纵向空间还给表格 |
| 10 | 数据条 | 夏普 / 卡玛列数字背后极浅品牌色条，长度 = 当前榜内相对位置 | Excel Data Bars 惯例 |
| 11 | 持仓/自选标记 | 见 §2.2 | 定位落地 |
| 12 | 行高 | 44px（design.md 表格行高基线上限） | design.md 数据表格强制紧凑原则 |

**暗色模式**：全部语义令牌（`--bg-card` / `--bg-hover` / `--bg-subtle` /
`--brand-100` / `-ink` 涨跌色），亮暗双端自动切换，无硬编码色值。

## 5. 合规边界（不变）

- 榜单是同类内的**相对排序**，不是买入信号；不荐股、不跟单、不预测；
- 收益列红绿是**涨跌语义**（正负事实陈述），不是好坏评价；风险列恒中性；
- `excluded_distorted` 必须可见——「榜上只有 3 只」与「同类只有 3 只有数据」
  是两回事；
- 口径元数据（窗口 / 样本数 / 口径版本）随页脚展示。
