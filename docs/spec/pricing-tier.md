# 付费 / 免费分层规范（pricing-tier）

本文件收录多多贝「付费 / 免费分层」的**定稿判定准则、功能归属表、双层估值开关与前端直连硬约束**，属于**低频变更**的产品决策类事实标准。定稿出处：`docs/working-notes/explore-watchlist-replan-2026-08-08.md` §9.6/§9.7（2026-08-09 与用户逐条确认对齐）；落地登记：issue #826。

## 1. 判定准则（定稿，2026-08-09）

任何功能上线前，按以下三条准则归类，**禁止凭感觉定价**：

1. **免费源 + 本地计算 + 无滥用风险** → **不限次免费**（零边际成本）；
2. **有真实边际成本（API 计费）或独特价值** → **限次 / 付费候选**；
3. **免费 → 付费禁止**（损失厌恶，已免费的功能不得转收费）；**付费 → 免费允许**（未来免费化仅调 quota，不涉及架构变更）。

## 2. 功能归属表（定稿）

| 功能 | 归属 | 说明 |
|---|---|---|
| 核心记账、导入导出、探市、温度计、自选、每日收益日历 | 免费不限次 | 本地计算 / 免费源，零边际成本 |

## 3. 双层估值开关（定稿，2026-08-09）

实时估值（`useRealtimeQuotes`）采用**双层开关**，语义：**平台级为总闸，用户级为个人偏好；平台级关闭时前端尊重总闸**。

| 层级 | 载体 | 状态 |
|---|---|---|
| 用户级 | 前端 localStorage `showbuy_realtime_quotes_enabled`（`useRealtimeQuotes.ts`） | ✅ 已实现 |
| 平台级 | 后端 env `REALTIME_QUOTES_ENABLED` + 配置接口 `GET /api/utils/config/` | ✅ 已实现（2026-08-14，issue #826） |

- 平台级用途：数据源压力过大或合规收紧时，后端改 env 即可一键关闭全站估值，**无需发版**。
- 平台级默认 `true`（未配置时保持现状，避免默认关闭导致线上估值突然消失）。
- 配置接口加入鉴权白名单（`PUBLIC_PREFIXES`），探市页 `/explore` 免登录访客也能读到总闸。

## 4. 估值前端直连约束（硬约束）

高频估值必须**前端直连行情源**：1000 用户 × 盘中 4 小时 × 每分钟轮询 ≈ **24 万次/天**，后端 API 承载不了（也是成本黑洞）。后端只做低频工作：最佳数据源统计、用量计数、开关下发。

- 刷新档位：**30s / 1m / 90s**（用户可自选，`REFRESH_INTERVAL_OPTIONS = [15, 30, 60, 90]`，默认 30s）。
- 前端直连是既有架构（#807 `useRealtimeQuotes` 三级降级：官方 fundgz → 新浪 → 腾讯兜底），**确认保留并作为正式约束**。
- Supabase 放高频数据是伪需求：Supabase 只存用户账本（低频），行情走行情源前端直连。

## 5. 通用用量表（付费候选落地预留）

拒绝每功能建表，统一用量表设计（§9.6 定稿）：

- 表：`user_usage(user_id, feature, period_date, count, quota, updated_at)`
- feature 枚举：`ocr_import`、`scheduled_sync`、…（按需扩展）
- 通用接口：`GET /api/usage/{feature}`
- 配额可配置（env / 表）

OCR 费用评估（Ark doubao vision）：单次 ≈ 0.0037 元；1000 用户 × 5 次/天上限 ≈ 555 元/月顶格，现实 20% 活跃 ≈ 74 元/月——**可承受**。
