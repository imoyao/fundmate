## 一、目标定义（基础可用版）

尽快上线一个**基础可用版本**，硬指标：

1. **探市页可用**（免登录沙盒 + 登录态感知 + 收藏）
2. **温度计页可用**
3. **系统部署上线**（部署形态 / 日志追踪 / 双备份）
4. **应用站部署上线**

约束（顶替方案，权威源 #917）：

- **记账唯一入口 = 多多贝应用站（FundMate，app.duoduobei.com）**
- **叽咕（jigu，基估宝，jigu.duoduobei.com）先承接访问**，设缓冲期，通过 SSO（#1029）打通后逐步迁移记账心智到 FundMate；缓冲期结束 jigu 退役归并
- jigu **仅展示/导流，不提供记账**

## 二、四象限划分原则

- **Q1-RED（重要且紧急）**：不上线就卡住的阻塞项。仅放真正阻塞「探市/温度计可用 + 部署 + 记账闭环」的工作。
- **Q2-YELLOW（重要不紧急）**：上线后增强、增长、扩展能力。解析器链、分析模块、付费等。
- **Q3-GREEN（紧急不重要）**：技术债务、体验打磨、自选展示增强（应用站用 jigu 顶替期间 fundmate 自选不精做）。
- **Q4-GRAY（不重要不紧急）**：远期/暂缓决策类。
