### 1.1 四象限优先级定义（永久标准）

- **第一象限｜重要且紧急**：阻塞核心流程、产生数据错误、影响上线的任务，48小时内闭环

- **第三象限｜不重要但紧急**：临时环境、依赖、报错问题，极简快速修复
- **第四象限｜不重要不紧急**：UI美化、细节打磨、远期创意，统一延后归档

### 2.4 复盘能力差异化计划（来自同花顺投资账本体验痛点 · 2026-08-03）

> **背景**：资深投资者（EarlETF）体验同花顺"投资账本"后指出两大痛点：① 收益率计算黑盒（显示 12.69% 但不解释算法，与作者自算的时间加权 13.01% / 资金加权 12.8% / Modified Dietz 12.79% 均对不上）；② 回撤分析仅标"最大回撤"极值，无连续回撤曲线。这两点正是多倍贝可碾压大厂工具的差异化入口，已落地于 `landing.html` 的「专业复盘」区块与对比表。
> **当前状态**：XIRR 已上线（P1-10），但时间加权 / Modified Dietz 多算法同屏展示、每笔现金流追溯、连续回撤曲线均为**待开发**。
