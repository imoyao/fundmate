# 版本更新记录（changelog）

**版本**: v4.8.5
**最后更新**: 2026-08-15
**核心原则**: 本项目为**个人 / 家庭使用、云端权威 + 本地缓存、完全合规**的投资记账工具（架构必须上云，D3 2026-08-07 取消「永不上云」承诺；详见 `docs/dev/db-data-domain.md`）。
**文档属性**: `docs/spec/` 体系为项目唯一事实标准（原单一 `SPEC.md` 已于 2026-08-01 拆分为本多文件体系）。所有开发必须严格遵守，禁止私自变更规则。
