## 意见反馈与功能吐槽

我们软件的初衷是帮助普通用户做好基金投资管理这件事，如果是其他定制化需求，我们只能在有余力且的确可以帮助到用户的前提下尽量满足大家。所以提出需求前，请务必仔细审视自己的问题。需求太多，我们可能会由于注意力分散导致难以维护下去哦~

::: tip
如果您是开发者或者想第一时间得到我们的回应，我们**强烈建议**您去 [Discussions](https://github.com/imoyao/FMP/discussions) 页面和我们建立联系！
::: 
如果你还没有使用过相关产品，请点击 [GitHub Discussions 文档 - GitHub Docs](https://docs.github.com/cn/free-pro-team@latest/discussions) 页面了解产品如何使用。
