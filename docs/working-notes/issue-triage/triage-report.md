## 0. 两条铁律

1. **文档 ↔ issue 交叉引用**：文档和 issue 处于交叉状态时必须互相链接，否则后期无法关联。
2. **文档 ↔ 历史差异拉平**：文档说"已实现"但代码没落地的，必须标出来并拉平，不能各是各的。

## 1. 复核方法

- **不再看标题**：对 9 个"已实现"关闭项，用 code-explorer 子代理做**严格代码实证**（真实路径 + 关键函数/类名 + 是否真的落盘）。
