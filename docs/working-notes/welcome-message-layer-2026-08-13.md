# Welcome 首页消息层改造（2026-08-13）

## 背景

投资概览（welcome）此前叠了多处死数据（风险热力图、收益趋势、资产变动趋势、财务晴雨表四项），且时间线重复、无真实数据源。经过多轮讨论（见 `page-split-welcome-vs-panorama-2026-08-13.md` 的分层原则），确定 welcome = 理想/目标 + 表现 + 预警，并落地为「首页消息层」。

## 分层原则（本次讨论再次确认）

- **日频 / 实时 → 首页看板（welcome）**：快照、收益趋势、温度、XIRR、动态风险预警。
- **结构切片 → 资产总览（panorama）**：五笔钱、品种、账户、资产负债、风险分层。
- **周期性派生洞察 → 复盘 / 报告页（asset-review 等）**：时间切片绩效、收益日历、调仓时间线、**投资人格雷达**。

一句话：**会动的首页放，不动的进报告。**

## 本次落地内容（frontend/src/views/welcome/index.vue）

1. **顶部消息播报 ticker**：原「你已记账 X 天」下新增轮动消息条，5s 切换。消息全部由真实数据派生（`buildHomeMessages()`，各 fetch 完成后组装）：家庭总资产、累计盈亏、年化收益率（XIRR）、市场温度、温度结论、记账天数。加载中显示「数据加载中，稍后为你播报…」。配套 `ticker-fade` 过渡动画，定时器在 `onUnmounted` 清理。
2. **财务晴雨表 → 「即将上线」空态**：删除 4 个编造百分比（资产负债率 49.03 / 预估储蓄率 46.06 / 财务自由度 22.83 / 躺平度 12.31），改为空态占位卡，注明接入资产负债表与现金流测算后展示。等后端真实测算。
3. **近期动态 → 真实数据 feed**：原「暂无记录 + 灰色占位条」空壳改为 `homeFeed`（computed），由真实数据派生：累计盈亏、XIRR、市场温度、记账天数、温度结论，色点区分涨跌/中性。后端事件日志就绪后可替换为事件流。
4. **删除重复时间线**：财务晴雨表卡内嵌的「资产变动趋势」迷你柱图（`[15,25,45,65]` 死数据）整块删除。
5. **死数据清理**：
   - 风险热力图（`[85,60,30,55]` 写死）从首页移除——风险预警改由 ticker 承载（分层原则：不动的数据不占首页）。
   - 收益趋势假折线（`[120,190,170,220,280,250,310]`）删除，卡片改为「即将上线」空态。
   - 家庭资产看板「本月资产增加 / 本月负债减少」（`28973.83` / `-20406.12` 写死）改为「— 即将上线」占位。
   - 资产构成分布饼图 fallback 假数据（`[856240, 678950, 810488, 212400]`）改为空态（无数据时显示「暂无资产数据」）。
   - 删除无用图表 ref（`trendChartRef` / `riskHeatmapRef` / `miniAssetChartRef`）、`financialMetrics`、`trendMode` 及对应 echarts 分支。

## 遗留 / 待办（不随本次落地）

- **投资人格雷达**：方案已有（`trading-personality-h5-plan-2026-08-10.md`，五维：出击/纪律/专注/切换/逆向），behavior 引擎 + API + 雷达图均未实施。**落点修订**：不进首页，进 asset-review 复盘页「行为体检」板块；welcome 仅在有新扫描结果时显示「已更新」入口卡。月度扫描产出五维得分 + 派生预警（集中度超标、换手率过高、追高迹象等）。
- **财务晴雨表后端**：资产负债率 / 储蓄率 / 财务自由度 / 躺平度 需基于资产负债表与现金流实现真实测算。
- **收益趋势 API**：累计收益 / 净资产时间序列，支持月/季切换。
- **事件日志**：近期动态 feed 替换为后端事件流（导入交易、XIRR 重算、创新高、温度越界等）。
- **站内信后端**：header 铃铛 / 未读指示目前为前端示例数据（`lay-notice`），ticker 目前只播可计算的洞察消息，订阅消息等站内信就绪后接入。
