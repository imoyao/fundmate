## 1. 横向滚动条与「默认列预算」

### 1.1 事实
- #1341 修的是**页面级**溢出；本次是**表格内部**横向滚动。
- 默认可见列总宽 ≈ **1282px**（加备注列 180 = 1462px）。
- 侧栏固定 **240px** → 1366 屏内容区 ≈ **1040–1080px**。

### 1.2 分辨率调研（2024–2025）
- 桌面端 **1920×1080 ≈ 43%** 主导；1536×864、1366×768 仍占相当比例；笔记本 2.5K ≈ 40% 在涨。
- 设计下限取最受约束的主流笔记本 **1366×768** → **预算 ≤ 1040px**。

### 1.3 【已定】列预算与「列集策略」
- **预算 1040 写进 `frontend/design.md`**（规范，非一次性取舍）。
- **不以"藏列"为手段**；超预算列走「列设置」；用户自行加列导致滚动属正常。
- **(a) 与 (c) 合并为一套机制**——按**视图**分层：
  - **混合视图（未筛选/多品类混排）**：只显示**所有品类都有意义的通用列**（差异化列不出现——否则恒为 `—`，无意义）。
  - **品类视图 / 类型筛选命中单一品类**：显示该品类的**完整列组**（含差异化列）。
  - **用户手动开启的列**：任何视图都显示；对当前标的不适用时显示 `—`。
  - 判定：**`—` = 用户主动加的列在当前标的无意义；隐藏 = 当前视图不含该品类**。
- 备注等**编辑能力不依赖列可见**（§7）。

### 1.4 【待定】
- **混合视图通用列集的确切清单**（见 §9-a）。

## 3. 各品类默认列组（含关联层）

**判断标准**：该列是否让用户**一眼做决策**。
**跨品类原则**：列要**可比较**；**含义随标的而异的字段不进默认列组**，或配校准辅助列（如"运行天数"）。

### 3.1 基金（场外）
`名称 | 净值估算 | 日涨跌幅 | 近1月 | 近1年 | 最大回撤 | 基金经理 | 对应场内`
- 差异化：**最大回撤**上列表、"**基金经理**"列（选人）；「对应场内」见 §3.8。
- 估算宽度 ≈ **760px**（含"对应场内"入口列 ~90px）。
- **「最大回撤」口径见 §3.10**（主动类绑定**现任经理任期**，非固定窗口）。

### 3.2 股票
`名称 | 最新价 | 日涨跌幅 | 行业 | PE | 成交额` — 差异化：**行业前置**。宽度 ≈ **610px**。

### 3.3 ETF
`名称 | 最新价 | 日涨跌幅 | 跟踪指数 | 规模 | 溢折率 | 关联场外`
- 差异化：**跟踪指数**不可省；「关联场外」= **数量标记 + 浮层**（`关联场外 2只 ▾`，不占列宽）。宽度 ≈ **760px**。

### 3.4 指数
`名称 | 最新点位 | 日涨跌幅 | PE | PE分位数 | 关联标的`

### 3.5 基金经理

### 3.6 投顾组合
`名称 | 平台 | 主理人 | 成立以来年化 | 近1年 | 最大回撤 | 运行天数` — **无对标**。宽度 ≈ **680px**。

### 3.7 可转债（独立品类：条款博弈优先于价格）

### 3.8 跨渠道关联（ETF / 指数 / 场外基金 / 股票）+ 份额关联（合并 §6）

**闭环**：`指数 ←→ 场内ETF ←→ 场外联接/指数基金`。

- **入口形式（已定）**：关联关系**不在默认列展开**，用**「数量标记 + 浮层」**（保列宽紧凑）；浮层里给**可比较**的关键数据。
- **优先级（已定）**：指数（最高，指数不可买、关联即"可投资性"）> ETF（中高）> 场外基金（中，反向辅助）> 股票（低，延伸）。
- **数据模型（预留，双向可查）**：
  - `FundIndexLink`：`fund_code / index_code / link_type(tracking|linked) / is_primary`
  - `CrossVenueLink`：`source_type/source_code / target_type/target_code / link_type(etf_to_otc_linked|otc_to_etf|index_to_etf|index_to_otc) / share_class(A|C|E)`
- **数据获取分层**：
  1. **ETF ↔ 场外联接**（易，**本期**）：命名规律（"XXX ETF联接A/C"）+ 类型过滤；精确用定期报告持仓（联接持仓含目标 ETF 代码）。
  2. **指数 ↔ 场内 ETF**（中，**本期**）：基金档案"跟踪标的"结构化字段；兜底用中证/国证指数官网"指数-挂钩产品"表。
  3. **指数 ↔ 场外指数基金**（中偏难，**后期**）：名称/投资目标解析；被动 vs 增强分类型处理。
  4. **股票 → 持股基金**（**后期**，股票品类扩展）。
- **A/C 份额关联**（原 §6，合并至此）：同一基金不同份额（看 A 类业绩、买 C 类费率），放**抽屉/浮层**；远期。
- **浮层字段（建议待定，§9）**：规模 / 费率 / 近1年（+ 操作入口）。

→ 这正是 §1.3「通用列走混合视图、差异化列走品类视图」的依据。

### 3.10 最大回撤口径规则（【已定】）
> 核心：**回撤是"管理人的风险特征"，换人即重置**——主动类绑定"**有效管理人任期**"，而非固定窗口。

**分品类口径**：
| 品类 | 回撤窗口 |
|---|---|
| 被动指数 / ETF / 联接 | 固定窗口（默认**近3年**） |
| 指数增强 / 量化 | 优先现任任期，任期不足则固定窗口 |
| 主动权益 / 固收+ / FOF | **现任经理任期** |
| 投顾组合 | **现任主理人任期** |
| 可转债 | 不适用（用强赎/回售条款代替） |

**主动类任期回撤决策树**（任期阈值 **T = 1 年**；频繁更换 = **近 3 年 ≥ 3 任**）：

```
现任任期 ≥ T → 现任任期最大回撤（标注"任期 X年X个月"）
现任任期 < T，且上一任任期 ≥ 2年 → 上一任任期回撤（灰色"上一任"）
现任任期 < T，且近3年更换 ≥ 3任（频繁）：
    ├ 历任任期年化 ≥ 同类前1/3 → 近3年固定窗口，**中性色**，tooltip"经理更替频繁，但历任业绩优秀"
    ├ 业绩中游及以下 → 近3年固定窗口，**橙色警示**，tooltip"近3年更换 N 任，业绩平庸，疑似试验品"
    └ 数据不足（多数任期<6个月）→ `—`，tooltip"管理人不稳定，数据不足"
成立不足 T / 数据缺失 → `—`（抽屉说明"数据不足"）
```

- **关键判断**："换任频繁"本身不是警示唯一条件，**频繁 + 业绩不行**才警示；频繁但每任能打＝公司投研平台能力，不警示。
- **数据模型（存口径元数据，不只存数字）**：`max_drawdown / max_drawdown_basis(current_tenure|prev_tenure|fixed_3y|insufficient) / max_drawdown_window / manager_tenure_days / manager_changes_3y / manager_perf_tier`。
- **视觉**：按 `basis` 决定色与 tooltip；详情/抽屉里回撤旁加"**口径**"小标签（点击说明为什么是这个窗口）。
- **计算**：自算，基于**天天基金全量历史复权净值序列**；固定窗口默认近3年（列设置可切近1年/成立以来）。
- **行业依据**：全行业任职年限中位数 4.42 年、2 年内占比近三成；T=1 年为"统计意义 vs 不误伤次新"的平衡点。
