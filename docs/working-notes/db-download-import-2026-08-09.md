# DB 下载导入层设计（2026-08-09）

> 性质：内部备忘（`docs/working-notes/` 屏蔽出构建）。解决「初始化/迁移时全量同步慢、云端全量拉取不可行」的问题（用户实测：云端全量拉取很慢，且东财抓取受 IP 封禁限制）。

## 问题背景

- 同步入口现状（`backend/app/tools/sync_metadata.py` + `sync_cli.py` + `services/sync/orchestrator.py`）：
  - `--all`：日常**增量**（核心池 = 持仓 + 自选 + CSV；`fund_nav_job` 增量「上次同步后 N 天」）；
  - `--full-sync`：全量（**仅限初始化/修复场景**）；
  - `--targets / --target-file`：单只/CSV 定向回填。
- 全量同步无范围限制 → 新用户初始化或本地库重建时，数据量大（净值表 868MB 量级）、云端全量拉取慢、且触东财 IP 封禁（`eastmoney-antiscrape-2026-08-05.md`）。

## 决策（用户拍板）

**新增 DB 下载导入层**：用户下载预打包的 DB 快照文件，在本地导入——**禁止云端全量拉取**。

## 设计

### 1. 快照打包（服务端）

- 由权威库（本地 SQLite，未来 Turso 市场域）定期/按需导出：
  - 生成**只读快照**：净值表、基金基本信息、指数、自选种子等**市场域数据**（不含用户私有账本；用户域走登录同步）。
  - 打包格式：SQLite 单文件（`.db`/`.sqlite`），可选压缩（`.gz`/`.zip`）。
- 产出物命名：`snapshot-YYYYMMDD.db(.gz)`；保留最近 N 份。

### 2. 分发与下载

- 用户/运维从管理端或独立下载入口获取快照文件（文件放在静态可下载位置，如 EdgeOne Pages 静态目录、或后端 `GET /api/sync/snapshot/` 受控下载）。
- **下载走文件通道，不走 API 全量拉取**——即用户拿文件、本地导入。

### 3. 本地导入（客户端）

- 新用户初始化 / 本地库重建流程：
  1. 下载快照文件；
  2. 校验（文件头 magic、日期、版本、checksum）；
  3. **导入本地 SQLite**（替代 `--full-sync` 的全量拉取）：
     - 仅导入**缺失记录**（按 code+date 去重，见下）；
     - 导入完成后进入日常 `--all` 增量模式。
- 与现有导入器（`services/importer/` CSV/PDF）分叉：这是**数据库文件导入**，不是交易单据解析。

### 4. 去重与合并规则

- 净值表按 `(code, nav_date)` 唯一键去重（upsert，不覆盖本地已存在记录）；
- 基金基本信息按 `code` 去重，快照较新则更新；
- 索引类数据按日期段增量合并。
- 合并规则与现有 `--targets` 增量通道共用同一套幂等逻辑（`fund_nav_job` 的 upsert）。

### 5. `--full-sync` 范围限制（强制）

- `--full-sync` 仅允许以下场景，且**必须带范围**：
  - `--full-sync --targets <code>[,<code>...]`：单只/多只全量回填（历史数据录入/修复）；
  - `--full-sync --target-file <csv>`：CSV 指定范围全量；
  - 裸 `--full-sync`（无范围）= **拒绝执行**，提示改用 DB 下载导入层或指定范围。
- 全市场全量仅剩一条路：DB 快照下载导入（本设计）。

### 6. 边界与不做的事

- 不做：用户私有数据（positions/transactions/自选）进快照——那是账号云同步的职责（P2-23），不是下载导入层。
- 不做：自动定时生成快照（初期手动/按需触发即可）。
- 不做：快照增量差分（一期只做全量快照，增量靠日常 `--all`）。

## 落地清单（挂 issue #「DB 下载导入层」）

1. 后端：快照导出命令（`pdm run sync --snapshot <path>`）——复用现有读写管线，导出只读 SQLite 文件；
2. 后端：`--full-sync` 裸调用拒绝 + 范围强制校验（`sync_metadata.py` 参数校验）；
3. 后端：`GET /api/sync/snapshot/` 受控下载（或静态文件托管，二选一，视部署形态）；
4. 客户端/CLI：快照导入命令（`pdm run sync --import-snapshot <file>`），含校验 + upsert 去重；
5. 文档：同步入口职责说明更新（`--all` 日常 / `--full-sync` 限范围 / `--snapshot` 导出 / `--import-snapshot` 导入）。
