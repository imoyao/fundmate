## ✨ 现在可以做什么

**多账户合并算总账**
把银行、券商、基金、投顾账户归到一起，看到家庭真实的总资产与真实收益率（XIRR 资金加权，精确到日），不用再自己对着几张表加总。

**持仓穿透到底层**
买了几只基金，能看到它们最终压在哪些行业和个股上，持仓市值占比一目了然。

**一句话就能问**
「我的钱现在亏了多少」「哪些该减了」——账本精灵直接读你的真实数据回答，不给泛泛而谈的建议。

**导入不用手敲**
券商流水、盈米等同花顺数据都能导进来，自动对齐。

**市场温度计**
不用登录就能看全 A 的估值温度与行业拥挤度，判断当前位置贵不贵。
