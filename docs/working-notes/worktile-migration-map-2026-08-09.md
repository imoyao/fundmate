## 2. 拟新建 issue（4 条）

### N1 ｜【分析】基金相关性与持仓重叠度分析

- 来源：WT#152（2021-07-17）
- 标签：`分析`、`enhancement`
- Status：`Todo`　象限：重要不紧急
- 正文要点：基于净值的相关性分析 + 基于持仓的重叠度检测（协方差/聚类）。用户原始诉求明确指出**要基于持仓判断重叠而非净值走势**——且慢只看净值，会把煤炭指数和白酒基金判为相关性 1。仅对低换手率基金有效。
- 前置依赖：基金→重仓股数据未入库（roadmap P2-25），需先建季报十大重仓股数据源。
- 关联：roadmap P2-10 / P2-26、`thermometer/README.md` B4

### N2 ｜【工具】定投计算器

- 来源：WT#141（2021-06-07）
- 标签：`工具`、`enhancement`
- Status：`Todo`　象限：重要不紧急
- 正文要点：支持组合（账户）定投与单只基金定投两种测算。参考好买、智投星。
- 现状：仅 `investment/manual` 有 `drip: "定投"` 交易类型标签（给已发生交易打标），无任何测算逻辑。

### N3 ｜【bug】组合页面路由未注册，账户页入口点击 404

- 来源：本次核查发现（WT#137 关联）
- 标签：`bug`、`前端`
- Status：`Todo`　象限：**重要且紧急**（已有入口按钮，用户点了就是 404）
- 证据：`views/asset/portfolio/index.vue`（7.5KB）+ `detail.vue`（20.4KB）+ `api/portfolio.ts`（6 函数）齐全，后端 `domains/portfolios/` 完整并已注册 blueprint；但 `router/modules/asset.ts` 的 children 无 portfolio 项，而 `ledgers/index.vue:20` 存在跳转按钮。
- 附带议题（来自 WT#137 原始设计诉求）：当前组合是 `Portfolio ← Ledger ← Position` 两级间接结构，即「把多个账户归组」；WT#137 期望的是「把多只基金自由组合」，两者语义不同，需产品定调是否支持后者。

### N4 ｜【探市】韭圈儿 fetcher 已实现但未注册进聚合流程

- 来源：本次核查发现（WT#136 关联）
- 标签：`探市`、`bug`
- Status：`Todo`　象限：重要不紧急
- 证据：`thermometer/fetchers.py:415-542` 的 `JiucaishuoFetcher` 128 行完整实现（API 优先 + Playwright 降级），模块 docstring 将韭圈儿列为「稳定层」，但它未出现在文件末尾的 `SINGLE_FETCHERS` / `COMPOSITE_FETCHERS` 注册表中，`jobs.py` 实际不会调用。
