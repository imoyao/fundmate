# 账户详情页信息重构计划（2026-08-27）

## 背景与决策

用户在使用账户详情页时发现三处体验问题，经讨论确定方向：

1. **配置目标列应可编辑**：持仓明细表格的「配置目标」列当前是只读徽章（`Position.allocation`），且因模型默认 `'longterm'`、账户 `default_allocation` 不回写已有持仓，导致同一账户内全部显示为「长期增值」。最终方向是支持**按持仓编辑配置目标**（五笔钱）。
2. **资产配置环形图在单账户维度无意义（方向 C）**：账户详情页环形图数据源是 `summaryData.type_distribution`（账户内按产品类型聚合）。单一类型账户（基金账户=全基金、股票账户=全股票）只能是 100% 单切片，信息量为零。结论：账户详情页**直接不显示**该环形图（资产配置聚合视图在组合页/全家总览更有价值，那里已有跨账户混合数据）。
3. **盈亏走势暂停**：该区块为占位，数据依赖 `P1-20`（APScheduler 定时任务体系，路线图 `⏸️ 未开始`）。当前无数据来源，暂停展示。

## 已落地（简单收尾，PR 待合入 dev）

- 账户详情页 `detail.vue`：移除「资产配置与盈亏走势」双列卡片（环形图 + 盈亏走势占位），清理死代码（`AssetAllocationDonut` 导入、`trendPeriod`、`typeColorMap`、`allocationData`、`initLineChart`）。
- 原位置替换为「账户深度分析（规划中）」占位卡，指向本记录，避免页面突兀留白。
- 注：`LedgerAllocationCard`（账户列表/总览页的跨账户配置分布）**保留**，它本就有信息量。

## 待规划落地（分期，本次不做）

### P0 · 持仓级配置目标编辑
- 后端：新增/扩展持仓更新接口，接受 `allocation`（五笔钱枚举），写回 `Position.allocation`；导入时允许携带。
- 前端：持仓明细表格「配置目标」列改为可编辑（下拉/徽章内联编辑），保存走持仓更新接口。
- 关联：账户 `default_allocation` 仍作为新建持仓的默认值，但需明确「是否回写已有持仓」——建议不自动回写，由用户显式编辑。

### P1 · 基金账户深度分析（持仓维度）
- 持仓集中度（HHI / Top N 占比）、当前持仓、持仓结构（股票型 / 混合型 / 其他型）。
- 投资风格、行业分布、股票分布、资金流向。

### P2 · 盈亏展示
- 月度盈亏分布、热力图、盈亏列表。

### P3 · 收益展示
- 收益率（柱状图 / 日历图）、日收益 / 月收益 / 年收益。
- 基础数据：收益率、盈亏金额、总资产（部分已由概览提供，需整合到分析卡）。

## 依赖与风险
- 行业 / 风格 / 资金流向等需要后端 enrich 数据源（参考 `e-account-import-data-decentralization-plan-2026-08-16.md` 的「前端下沉静态源」思路：分类/行业/风格可下沉前端静态，净值/用户数据留后端）。
- 盈亏/收益历史曲线依赖 `P1-20` 定时任务落地，优先级低于上述展示重构。

## 关联
