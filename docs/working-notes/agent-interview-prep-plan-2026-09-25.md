### 1.4 LangGraph 定位：选型决策，不落地、不列技术栈（2026-09-25 评估结论）

> 三档取第三档：**不是项目使用的技（不落地），也不止于口头调研（写实成决策）**。

- **不落地的依据（仓库既有冻结立场，本次仅确认不改）**：
  | 位置 | 内容 |
  |---|---|
  | `docs/spec/decisions.md` D19（2026-08-17） | 「**不引 LangGraph**，采用轻量封装」——冻结区，改须先记新决策，而本次评估认为**无改的理由** |
  | `docs/spec/roadmap.md` P2-31 及「无编排框架兜底」 | 同一立场二次记载 |
  | `backend/app/services/ai_recognizer/agent_loop.py:5` | 代码注释：「不引 LangGraph；用轻量循环做状态路由」 |
- **为什么不引入**：Agent 只有 `ask_clarification / execute_tool` 两状态，LangGraph 核心价值（复杂图 / checkpointer 断点恢复 / 人工审批节点 / 多 Agent）**收益为零**；引入 = 依赖 + 学习成本 + 项目变重，撞主线 §8【最高】风险「跑偏成学框架」。
- **为什么简历不写「用过」**：写「用过」第二问必然是「checkpointer 怎么处理中断 / graph 拆几个 node」，浅用即穿帮（与编造数字同性质）；且会模糊掉最硬的牌——**230 行自研状态机 + 14 个单测 + 自审出 5 个真问题**。「为什么不用 X」比「我用了 X」更显资深（考 trade-off vs 考使用经历）。
- **三条落地口径**：
  1. 技能栏 / 技术栈关键词：**不列** LangGraph（列了等于承诺用过）；
  2. 项目经验架构 bullet 出现**一次**，写成决策：「编排选型评估 LangGraph 后，基于两状态循环选择自研轻量状态机，拒绝引入编排框架（决策记录 D19）」；
  3. 口述三段式：**为什么不用**（两状态，框架收益为零）→ **成本**（依赖 / 黑盒 / 学习曲线）→ **何时会引入**（状态数 >5、需持久化工作流与人工审批节点时，见主线 §反过度设计表）——末句边界是加分核心。
- **痕迹可验证**（「调研过」的实证，不是嘴上说）：D19 决策记录 + roadmap 记录 + 代码注释 + 头脑风暴文档 Q4 演进（`investment-agent-brainstorm-2026-08-17.md`：可选 → 同花顺实证 FC 循环即可 → D19 定案）。

## 6. 企业级包装：真实事实 → 企业级术语（只翻译，不造数）

> **判断依据（2026-09-25 对比评估）**：Gitee `ai_black_ma/ai` 看起来更企业级，是因为它**把企业级词条全占了**（分库分表/限流熔断/全链路追踪/监控/CI 全有设计文档）——但 95 份文档里 13 份是 `07-面试准备/` 面试话术、规模数字只存在于文档、测试仅约 10%。fundmate 是反着的：**里子厚（Python 9.7 万行 vs 2.6 万行、测试 3.7 万行 vs 2.5k 行、264 份规范文档、11 条 CI workflow）、缺翻译**。企业级感 = 术语密度 + 叙事结构，不是规模数字。

| fundmate 真实事实（有 file:line 可指） | 企业级表述（简历/面试可用） |
|---|---|
| `DATA_DOMAIN_REGISTRY` 双引擎路由、跨域零 join、两步法读取 | 多数据域架构：数据分域 + 应用层路由与隔离 |

| `ci.yml` 质量门禁 + 分支保护 + 乱码/v1 引用等守卫脚本 | CI/CD 质量门禁与多层自动化守卫 |
| 数据准入四问（`docs/spec/data-strategy.md`） | 数据治理：按场景准入、控制存储成本 |

| Vercel/Cloudflare 部署 + Turso/Supabase 双库 | Serverless 生产部署、多环境数据层 |

**两条红线**：

1. **只翻译、不造数**——Gitee 题库里的 10 万 DAU / 99.9% / QPS 2000 一律不借（同 §1.3 口径）；
2. **三个真短板问到就认，不硬编**：① 高并发实战数字 ② 分布式缓存 / 消息队列 ③ metrics 监控栈（Prometheus 类）——答法：「个人产品真实规模是 __；按反过度设计原则不预置，但架构已留位（如 per-user 配额迁表就是为多实例做的准备）」。弹药在主线 §7「只学不做」清单，**不为此新增学习任务**。
