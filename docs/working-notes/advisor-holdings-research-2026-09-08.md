## 一、先澄清：你要的是哪一种"持仓"

| 概念 | 含义 | 举例 |
|------|------|------|
| **投顾组合持仓**（本文目标） | 一个投顾策略里包含哪些**基金**、各基金**占比**多少 | 远足 = 中泰星元10.3% + 国联优势产业12.8% + … |
| 单只基金持仓 | 一只基金的前十大**重仓股/债**及占比 | 某基金持有茅台 8% |

你要的是前者。下面所有内容都围绕"投顾组合持仓比例"。

## 四、且慢 MCP 方案（已打通，可作为"组合持仓"独立界面的首选数据源）

- 真实端点（SSE 模式 MCP，已在沙箱实测打通）：

  ```
  https://stargate.yingmi.com/mcp/sse?apiKey=<你的Key>
  ```

- 与组合持仓直接相关的工具：

| 工具 | 作用 | 对应你的需求 |
|------|------|------------|
| `BatchGetStrategiesComposition` | **批量获取投顾策略持仓基金及占比** | 组合持仓比例 ✅ |
| `GetStrategyDetails` | 策略基本信息（名称/风险/简介/成立日） | 组合基本信息 |
| `StrategySearchByKeyword` | 按关键词搜策略，返回 `策略代码` | 把"远足"映射到 `ZH012926` |
| `GetStrategyAssetClassAnalysis` | 策略大类资产分布（股/债/货基占比） | 资产配置比例 |
| `GetPortfolioNavHistory` | 策略历史净值走势 | 净值序列 |

- 可复用 Python 客户端（已实测可用）：

```python
import asyncio, json
from mcp import ClientSession
from mcp.client.sse import sse_client

KEY = "你的且慢MCP Key"
URL = f"https://stargate.yingmi.com/mcp/sse?apiKey={KEY}"

async def main():
    async with sse_client(URL) as (r, w):
        async with ClientSession(r, w) as s:
            await s.initialize()
            # 1) 搜策略代码（把组合名映射到 strategyCode）
            res = await s.call_tool("StrategySearchByKeyword", {"keyword": "远足"})
            # 2) 拉组合持仓（核心！返回各基金代码/名称/持仓占比/净值/类型）
            res = await s.call_tool("BatchGetStrategiesComposition",
                                    {"strategyCodes": ["ZH012926", "ZH030684"]})
            data = json.loads(res.content[0].text)
            # data 结构：{ "ZH012926": { "混合基金": {"持有成分":[...]}, "货币基金":{...}, "分类占比":"xx%" }, ... }
            with open("comb.json", "w", encoding="utf-8") as _f:
                json.dump(data, _f, ensure_ascii=False, indent=2)

asyncio.run(main())
```

> 依赖：`pip install mcp`（已在本环境装好）。注意 YM-Stargate 服务端用**流式 SSE** 推送大响应，手写 HTTP 客户端容易把 JSON 截断，建议直接用 `mcp` 官方 SDK。

## 六、蛋卷 / 雪球 现状（供参考，均对未登录态收紧）

| 平台 | 探测结果 |
|------|---------|
| **蛋卷**（雪球旗下基金平台） | `https://danjuanfunds.com/djapi/plan/TIAA644002` → `{"result_code":91003,"message":"没有找到该计划"}`；其 `position` / `rebalancing` 等持仓接口返回 `300001 请重新登录`。即：未登录不可取，且越海在蛋卷侧未以该码命中。 |
| **雪球** | 组合/投顾类接口（如 `/stock/forgroup/detail.json`、`/cubes/quote.json`）统一返回 `error_code:400016 "遇到错误，请刷新页面或者重新登录帐号后再试"`，需登录 token。 |

> 小结：越海所在的三个代销平台中，**雪球基金 / 同花顺 对未登录态已收紧**（组合/投顾持仓需登录 token，返回 400016 / 300001）；**天天基金则已打通免登录公开 API**（如越海 `tgCode=XCOVSEX`，详见 §五与权威文档），故天天基金侧无需登录即可取持仓。这是 2023 年以来平台分化后的现状：并非"全都收紧"，天天基金仍是公开可达的稳定源。
