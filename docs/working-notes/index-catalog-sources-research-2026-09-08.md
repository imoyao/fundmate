# 指数名录数据源调研与高价值指数清单（2026-09-08/09）

> 背景：用户调研公众号文章「基金投资该拿什么当基准」（万得偏股基金指数 vs 中证偏股基金指数），
> 提出「把有代表性的指数全部保存进数据库」的需求。本文为数据源调研结论与实测证据，
> 衔接 #1362 已落地的 `index_catalog` 名录底座与三源合并方案。
> 关联 issue：#1365（三源合并实施卡）；数据底座：#1362 / #1286。

## 一、实测结论（2026-09-08/09，akshare 1.18.91 实测）

对高价值指数在三大名录源的覆盖实测：

| 源 | akshare 接口 | 总量 | 缺失 | 说明 |
|----|-------------|------|------|------|
| 新浪 | `index_stock_info()`（**注意：无 `_sina` 后缀**） | 732 | 930950 / 932000 / 881001 | 交易所挂牌指数（sh/sz 前缀），中证系交叉挂牌的 000300/000852/000905/000922/000510 有收录 |
| 中证官网 | `index_csindex_all()` | 2364 | 881001；399 系 | **930950 / 932000 / 000510 / 000985（中证全指）全中**，中证专属代码唯一来源 |
| 国证官网 | `index_all_cni()` | 1465 | —（目标集内） | **399303 / 399317 / 399020 全中**，国证专属代码唯一来源 |

**结论：三源并集可覆盖除万得系外的全部主流指数；`881001 万得全A` 为 Wind 专有，无免费权威源，
以 `399317 国证A指`（国证源）与 `000985 中证全指`（中证源）作权威免费替代（两者均实测可得名录）。**

三源合并去重优先级：sina（带交易所归属，如 SH000300）> csindex（记 `CSI` 前缀，如 CSI930950）> cni（记 `CNI`，如 CNI399303）。

### 韭圈儿（funddb.cn）专项结论（2026-09-09，含决策修订）

**2026-09-09 修订**：后续实测推翻「已收口」结论——被试端点只是**估值曲线端点**（需登录），
而万得全A 相关的两个端点**免登录、无签名**可直接调用：

- `POST /v2/fundindex/detail`（date=月数，上限 120=10 年）：累计收益率序列

万得全A 点位经 `P(t) = P_now × (1+r(t)) / (1+r_end)` 反推派生（校验：最低点精确命中
2018-10-18 A 股大底）。这不算逆向（无签名破解），属公开源 best-effort 接入；
**稳定性风险自担**：私有接口可能无通知变更，930950 / 399317 始终是权威 fallback。

**落地**：`JiucaishuoAdapter` + `index_daily` 表（market 域）+ `IndexDailySyncJob`
（`pdm run sync --job index_daily`，全量 10 年/增量 12 月，upsert 覆盖同日）。
实网实测：2426 个交易日（2016-09~2026-09）3 秒入库。口径注意：**价格指数反推**，
非全收益；锚点随最新收盘平移，勿做跨年回测级依赖。

### 踩坑记录

1. `index_stock_info_sina()` **不存在**——akshare 文档接口名为 `index_stock_info()`；#1362 初版
   `fetch_index_catalog` 用错函数名会运行时 AttributeError（本调研实测抓出，已在 feat 分支修正）。
2. PowerShell 内联中文列名（`df['代码']`）会被 GBK 控制台编码毁掉（KeyError: '代码' 乱码形态），
   探针脚本必须走 UTF-8 文件执行（与 AGENTS.md「中文禁内联」同源）。
3. 中证/国证接口列名随版本可能变化（指数代码/简称），代码里按子串匹配列名做兼容
   （`_pick_col`，勿硬编码列名索引）。
4. **同接口跨版本形态漂移实证**：akshare 1.18.91 的 `index_stock_info` 返回英文列名
   （index_code/display_name）且代码**不带 sh/sz 前缀**（旧版为中文列名 + 前缀）。
   适配器已兼容双形态；新版裸码按「39 开头=SZ、其余=SH」的交易所惯例归属。
   首次回填时因未兼容此形态 sina 贡献 0 行（000300 被 CSI 抢归属），修复后总数
   4097（732+2364+1465 去重）。

## 二、基准层级与高价值指数清单（文章观点 + 交叉判断）

文章核心观点（经交叉判断认为专业可信）：

1. **万得偏股基金指数（等权）代表公募基金平均炒股水平，作为个人目标过高**；等权编制看似随机丢飞镖，实际是高水平指数。
2. **基金收益 ≠ 基民收益**：选基困难、调仓损耗、追涨杀跌、费率磨损使基金收益难转化为基民收益。
3. 更合理的渐进基准体系：大盘基金指数（超普通基民）→ **中证偏股基金指数 930950**（净值规模加权，超全体基民平均，行业趋势基准）→ 万得偏股基金指数（超公募平均）。
4. 文章具体推荐（创业板200 / 科创100 华夏 ETF）带营销属性，小盘成长风格的历史弹性不代表未来，仅作观察标的收录、不作投资建议。

## 三、实施记录（#1365，feat/index-catalog-multisource 分支）

1. `fetch_index_catalog` 修正函数名（`index_stock_info`）。
2. 适配器新增 `fetch_index_catalog_csindex` / `fetch_index_catalog_cni`，列名按子串兼容匹配。
3. `IndexCatalogSyncJob` 三源合并：fetch 顺序即优先级（sina > csindex > cni），单源失败不阻断；
   `exchange` 扩展 SH/SZ/**CSI**/**CNI**（统一编码命名空间前缀）。
4. 聚合搜索 `_search_indices` 的 code 归一化：`SH000300 / CSI930950 / CNI399303` 形态；
   CSI/CNI 条目 venue 为空串（非交易所挂牌）。
5. `MARKET_LABELS` 补 `CSI: 中证`、`CNI: 国证`（后端权威 + 前端镜像同步）。
6. 回填：`pdm run sync --job index_catalog`（或 invoke grab 通道）。
7. 后续（另卡）：核心指数白名单标记（层级/置顶），服务自选页「指数」分组的展示排序。
