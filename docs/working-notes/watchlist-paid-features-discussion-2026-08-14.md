# 自选付费化方向讨论（2026-08-14）

> 远期规划备忘，非实现项。用户提出自选功能付费化三大方向，要求先讨论、不急于实现。
> 本文记录讨论结论与待决策项，待用户明确方向后再推进。

## 背景

用户提出自选功能可做付费功能，三大方向：
1. 数据清理与提醒（一键扫描死数据 / 异常提醒 / 最大回撤提醒）
2. 持仓穿透分层（基础免费、深度收费）
3. 持仓建议与推荐（方向级，不提个股）

## 关键前提：品牌边界是公开承诺

`docs/design/brand-v1.7.md` 三处写死：
- L56 边界声明：「不荐股 · 不跟单 · 不预测市场——只帮你算清真实收益」
- L309：「我们不荐股、不跟单。所有数据由你手动录入或交割单导入，主权归你」
- L314：「数据主权边界（不变）：不荐股、不跟单、不预测市场」

**第 3 类直接撞上已公开承诺的品牌边界**，改边界 = 改品牌承诺，影响落地页/关于页/隐私页多处文案，且是公开对外承诺，不能悄悄改。

## 逐条结论（套用 pricing-tier.md §1 判定准则）

### 1. 数据清理与提醒

- **(a) 一键扫描死数据**：强赎/退市状态是公开数据 + 本地计算 → **免费**（准则第一条）。
  - **红线**：不能自动删用户数据。「清除」= 标记 + 提示 + 用户确认，或移入归档分组，绝不静默删除（与 AGENTS.md「禁止武断执行」同源，也是产品层数据主权承诺）。
- **(b) 异常提醒（ST/换基金经理）**：公开数据 + 本地比对 → **免费**；边际成本在**推送通道**（微信/邮件/短信）→ 免费站内提醒，付费多渠道推送（准则第二条）。
- **(c) 最大回撤提醒**：本地计算 → 按准则免费；「免费 n 名额 + 付费无限」是**配额分层**（freemium），不违反「免费→付费禁止」（该条禁止已免费功能转收费，非禁止新功能设免费额度）。**注意：免费名额一旦承诺即永久免费，不能日后收回。**

### 2. 持仓穿透分层

- pricing-tier.md 已写死「持仓穿透→免费不限次」。分层必须是**新增深度维度**收费，不能把现有免费穿透改收费。
- 例：基础穿透（重仓股/行业分布）免费；深度穿透（穿透后组合重叠度、风格归因、风险暴露）付费。边界须划清，否则违反「免费→付费禁止」。

### 3. 持仓建议与推荐 —— 与品牌边界冲突，需先决策

- 中国语境：证券投资咨询业务需持牌（《证券法》+《证券、期货投资咨询管理暂行办法》），监管红线是**收费荐股**和**个性化投资建议**。
- 「指大方向不提个股」比荐股安全，但仍属「投资分析/预测」范畴；一旦**收费 + 基于用户持仓个性化**，滑向投资咨询业务，有合规风险。
- **更安全替代：把「建议」降级为「客观数据呈现」**。项目已有温度计/行业拥挤度/估值分位——客观指标非观点。「有色行业拥挤度处于历史 90% 分位」是事实，「看好有色」是观点。前者让用户自决、守住「不预测市场」边界；后者替用户下结论、越界。
- **立场：第 3 类不建议做「建议/推荐」，建议做「客观数据洞察」**——把温度计/拥挤度能力延伸到持仓关联的行业/风格维度，价值保留、边界守住、合规风险最低。

## 待决策项

1. 第 3 类是否接受「客观数据洞察」替代「建议/推荐」？（涉及品牌边界，需用户拍板）
2. 若坚持做方向级建议，需评估：是否改品牌承诺、是否需持牌/免责声明、收费形态。
3. 第 1(c) 最大回撤提醒的免费名额数。
4. 第 2 类深度穿透的具体维度与收费形态。
