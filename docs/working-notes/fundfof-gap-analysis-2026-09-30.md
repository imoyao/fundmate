## 0. 结论先行

1. **你的 P0/P1 方向是对的，但排序的「轴」选错了。** 你按**功能**排序，而真正的成本瓶颈只有**一处数据**：基金季报持仓明细（基金 × 报告期 × 股票 × 占比）。这张表一落，**重仓股 / 行业穿透 / 重叠度 / 完整归因四件事同时解锁**——它们不是四个功能，是同一份数据的四种展示。所以 P0 不是"四件套"，是**一张表 + 一个页面**。

2. **fundfof 抄不走的两件事，恰好是我们的地基。** 它是"买入研究"工具，所有分析都基于**公开净值**；我们有 L1 真实持仓/成本/流水。由此产生三处它做不到、我们能做的差异化（详见 §4）：
   - **账户级**溃疡/回撤（它只能算基金净值级，我们能算"你的钱"经历了什么）
   - **零录入**组合穿透（它要你手工建组合，我们直接吃账本）
   - **实盘 vs 假设对照**（它的回测是模拟，我们的"回测"是真实流水复算）

3. **你的表里有两处事实性错误**（本文 §7）：
   - **市场拥挤度 / 行业热力图不是缺口**——探市页**已经有了**（`CrowdingTable` / `IndustryCrowdingTrend` / `BiasTable`），且已接 fundfof 外部源。**从待办里删掉。**
   - **A/C 份额持有成本平衡线被严重低估**——你放在 P2，但我们**数据齐备、近乎零成本**，且它最贴合"持有人的视角"。fundfof 的第 1828 次（最后一次）提交才做这件事。**建议提到 P0/P1 交界。**

4. **反向压力测试结论（§6）**：真正"看着热闹但不挣钱"的不是你标的那两条，而是 **事件中心 / 产业链传导 / 今日快讯**——成本最高、口径最不可控、对"优化我已有持仓"零直接帮助。**明确写进不借鉴清单。**

5. **二期起手建议**：先做 **`fund_holdings` 落库（目标池限量）→ 账户级风险指标（替换两个 mock 页）** 这两件。前者是穿透的前置，后者零新数据源且立刻消灭演示债。

## 4. 关键判断：我们的地基与 fundfof 不可比之处

作者在文章里反复强调"**持有人的视角**"——但他能给的只能是**基金净值级**的持有人视角（这只基金跌下去要熬多久）。**他永远拿不到你的账。**

| 维度 | fundfof | 我们 |
|---|---|---|
| 分析对象 | 公开基金净值 | **你的真实持仓 + 成本 + 流水** |
| 组合穿透录入成本 | 手工建组合 / Excel 导入 | **零成本**（直接吃 `positions`） |
| 回撤/溃疡口径 | 基金净值级（不管你何时买入、买了多少） | **账户级**（含你实际加减仓的影响）——同一个基金，不同人体验完全不同，只有我们能算 |
| "回测"的含义 | 模拟组合（假设历史持有） | **真实流水复算 + 假设调仓对照**（你能回答"如果我当时没加仓会怎样"，他不能） |
| 数据主权 | 站方持有 | **本地 SQLite / 自建**（我们已有"交易记录一键导出"作为承诺锚点） |

**推论（重要）**：凡是 fundfof **必须靠"全市场数据"才能做**的功能（排行、事件、产业链、快讯、全市场筛选），照抄等于把自己变成一个**没有账本优势的劣质行情站**；凡是 fundfof **只能做到"基金级"而我们能做到"账户级"**的功能（溃疡、回撤、穿透、归因），照抄是**升级**不是跟随。**这条线就是借鉴与不借鉴的分界。**
