### 产品需求说明：资产复盘页面

#### 1. 页面目标
为用户提供一个**时间切片式**的投资绩效分析视图，支持**周报、月报、年报**三种周期。核心目标是回答：**“这段时间我赚/亏了多少？和基准比怎么样？钱是怎么赚/亏的？”**

#### 2. 全局交互与布局原则（Web 桌面端适配）
-   **信息密度优先**：充分利用桌面宽屏（通常 1440px+），将核心图表和控制项平铺，减少垂直滚动。采用左右双栏或多列卡片布局。
-   **时间导航一致性**：页面顶部设置统一的时间维度切换器，所有图表和卡片需联动响应时间变更。
-   **对比基准可配置**：用户可选择对比基准（如沪深 300、上证指数），默认记忆上次选择。
-   **下钻能力**：所有汇总数字应支持点击/悬停，展示构成明细（如每日收益明细、盈亏排行榜中的持仓明细）。

#### 3. 核心组件需求详述

**组件 1：时间导航与控制栏**
-   **位置**：页面顶部，粘性定位。
-   **元素**：
    -   **周期切换器**：三个分段按钮，选项为`周报`、`月报`、`年报`。
    -   **时间穿梭器**：由 `<` 和 `>` 箭头及当前周期文本标签组成。文本标签示例：`2026年5月`（月报）、`2026年第20周 (05/11-05/17)`（周报）。用户可点击箭头前后翻页，也可点击文本标签弹出日期选择器快速跳转。
    -   **基准选择器**：下拉菜单，选项如 `沪深300`、`上证指数`、`创业板指`，默认选中 `沪深300`。
    -   **行为**：任何切换操作应立即触发全页面数据重载。

**组件 2：核心绩效摘要卡**
-   **位置**：控制栏下方，一行四栏等宽卡片。
-   **设计意图**：30 秒快速概览，回答最关键的盈亏和比较问题。
-   **卡片内容**：
    1.  **期间收益（金额）**：大号数字（正红负绿），标题“周/月/年收益”。下方显示环比变化（如“较上周（月/年） +3.2%”）。
    2.  **收益率**：百分比大号数字，标题“收益率”。下方显示年化换算（仅月报/年报显示）。
    3.  **基准对比**：标题“跑赢/跑输基准”。核心指标是 **与基准的相对差**（如“-0.42%”），用红绿色直观强化。副标题显示基准本身涨跌幅。
    4.  **投资者排名**：标题“击败 X%投资者”。显示该期间盈利投资者占比和用户排名，作为行为金融学参考。
-   **行为**：点击任意卡片，下方图表区的折线图应高亮对应数据系列。
**设计决策**：原方案"击败 X%投资者"因需要外部大样本数据、与本地优先原则冲突，移除此卡片（可列入远期计划）。

**组件 3：资产走势与盈亏分解图（页面的视觉重心）**
-   **位置**：摘要卡片下方，占据主要宽度。
-   **布局**：左侧大面积图表（占 65-70%宽），右侧为排行榜（占 30-35%宽）。
-   **图表（左侧）**：
    -   **类型**：复合图表。
    -   **数据系列**：
        -   **柱状图**：每日/每周/每月的**总资产市值**（对应周期粒度），使用左 Y 轴。
        -   **折线图**：**累计收益率（%）**，包含两条线：“我的收益率”和“所选基准收益率”，使用右 Y 轴。
    -   **交互**：鼠标悬停在任意时间点上，显示一个浮层卡片，包含：当日日期、资产总值、当日收益额、我的累计收益率、基准累计收益率。
    -   **视觉提示**：当“我的收益率”线在“基准”线上方时，中间区域半透明浅绿色；下方时，半透明浅红色。
-   **盈亏排行榜（右侧）**：
    -   **标题**：动态切换 “盈利先锋” / “亏损大户”。
    -   **列表项**：展示该周期内，按**盈亏金额绝对值**排名的资产（股票/基金）。每一项显示：名称/代码、盈亏金额（正绿负红）、盈亏百分比。
    -   **行为**：默认显示前 5 项，可展开显示全部。点击某一项，应跳转或弹出该资产的详细持仓页面。

**组件 4：收益日历（热力图）**
-   **位置**：走势图下方，独立区块。
-   **设计意图**：模仿 GitHub 贡献图，提供全年的收益分布鸟瞰图。
-   **实现**：
    -   **年视图**：53 列 x 7 行的格子矩阵，每个格子代表一天。颜色深浅映射当日收益额的绝对值（红涨绿跌，灰无数据）。
    -   **月视图**：自动调整展示单个月份的日历网格。
    -   **交互**：鼠标悬停在格子上，出现提示框显示“日期：收益金额”。点击某个日期，可将走势图的焦点锚定到该日，方便回顾。

**组件 5：交易行为复盘**
-   **位置**：收益日历下方，左右两列布局。
-   **左栏 - 调仓时间线**：
    -   一个垂直时间轴，列出该周期内所有买入、卖出交易。
    -   每一项显示：日期、交易方向（买/卖/转入/转出）、资产简称、数量、金额。
    -   对于“卖出”项，可计算并显示该笔交易的**实现盈亏**。
-   **右栏 - 资产配置变化（桑基图/双环图）**：
    -   展示“期初” vs “期末”的资产配置比例变化。
    -   分类维度可与全局过滤器联动（如：按资产类型、按市场、按账户）。
    -   这直观回答了：“我的钱是如何在不同资产间流动的？”

**组件 6：复盘笔记（个人思考区）**
-   **位置**：页面底部，独立私密区块。
-   **设计意图**：将投资决策的“数据”和“思考”绑定在同一视图。这是其他竞品没有的差异化设计。
-   **元素**：
    -   一个所见即所得的富文本编辑器（支持 markdown）。
    -   标题自动生成：如“2026 年 W20 复盘笔记”。
    -   **行为**：笔记**自动保存**到本地，并与复盘周期严格关联。用户翻看上期时，能自动加载对应的历史笔记。
    -   **提示**：可预设几个引导性问题作为占位符文案，例如：“本周最大的操作是什么？执行是否偏离了计划？下阶段要关注哪些风险？”

---

#### 4. 情感化设计与边界情况
-   **跑赢/跑输的庆祝与鼓励**：若跑赢基准，核心对比卡片可有微小的撒花动效；若跑输，则为冷静的蓝色调，并显示鼓励文案。
-   **空状态**：对于无交易或数据不足的周期，图表区不显示空白，而是用虚线引导：“导入你的持仓和交易流水，即可生成复盘报告”。
-   **综合评分**：P2 阶段可引入一个简单的评分雷达图（攻击、防御、稳健），从数据中推断投资风格，增加趣味性。

### 设计整合说明

> 请综合以下移动端报告的优点，重新设计一个**网页端**的资产复盘页面：
> 1.  **微众银行**：强项在“月资产变动”的面积图，和“持仓分析”中对资产特征的概括（如“短期不用的钱”）。
> 2.  **天天基金**：强项在“收益率曲线”的多基准对比，“收益日历”的完整视图，以及“当日/当周收益明细”的清晰列表。
> 3.  **支付宝**：“个股盈亏”的排序和风格分析。
> 4.  **投资周报类 App**：强项在“调仓记录”的时间线和盈亏总结。
>
> 设计时，请将这些元素在宽屏上重组，并用上述详细的组件描述进行替换和增强。所有数据问题（如数据源、计算）由我后续解决，你只需聚焦于界面和交互设计。
