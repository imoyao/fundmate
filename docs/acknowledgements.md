# 开源致谢

多多贝是一款个人投资记账与资产分析工具。它站在无数优秀开源项目与自由字体的肩膀上，我们在此一并致谢。

## 字体

界面中文由 **MiSans** 字体渲染，版权归小米科技（免费商用授权，官方说明见 [hyperos.mi.com/font/zh/faq](https://hyperos.mi.com/font/zh/faq/)）。西文与数字由 **Inter** 字体渲染（[SIL Open Font License 1.1](https://openfontlicense.org/)）。
