# 2026-07-29 探索页（explore/index.vue）温度区 UI/UX 优化讨论

## 已确认的设计方向（用户拍板）
1. **综合温度替代综合估值（不再显示 PE）**：综合温度由两源合成——
   - 源1：第三方参考数据按权重加权（韭圈儿恐惧贪婪/中长期、且慢、有知有行、集思录估值、东方财富成交额）
   - 源2：自算指标，**不使用 PE**（改用股债利差 spread，对基金用户更友好）
   - 当前综合温度卡先保留「算法开发中」占位，后续再接真实算法（后端尚无该合成接口）。
2. **韭圈儿恐惧贪婪指数**：卡标题由「短期情绪」改为「恐惧贪婪指数」；必须显示文字分级（后端 `label_fear` 已提供 7 级：极度恐惧/恐惧/偏恐惧/中性/偏贪婪/贪婪/极度贪婪）。
3. **统一颜色语义**：绿=偏低/机会区（可关注），红=偏高/拥挤/谨慎区（不建议追），**金（暖沙金 `--tag-warm-sand`）= 适中·平稳**。
   - 中性档用暖沙金而非灰，因国内站点惯例，金读「温和/平稳」不构成第三极性。
   - 注意：这是「估值温度」语义，**不是**涨跌语义；必须与观察列表的 红涨绿跌 区分，页面需图例说明 + 免责声明（合规红线）。
4. **信息分层**：用户选择 B（语义分组）+ 多个指标并列一级（非单一 hero）。
   - 一级锚点区并列：综合温度、恐惧贪婪指数、自算·股债利差
   - 二级分组：市场情绪（韭圈儿中长期/且慢/有知有行）、估值与专项（全市场估值/可转债/指数快照）、流动性（成交额）
5. **数据源暴露**：每张卡底部加 source chip，默认淡、hover 浮现，点击用 `links` 跳官网。

## 已发现的技术问题（实现时一并修）
- `index.vue` 温度标签样式引用了未定义的 CSS 变量 `--warm`/`--cold2`/`--ok`/`--mid`（colors.css 无定义），导致偏高/偏低/放量/缩量/恐惧贪婪的文字色失效（视觉混乱根因之一）。`.temp-card-level`（低估/高估）用的 `--color-rise/--color-fall` 正常。
- 大量上一版废弃样式残留（.hero-section/.market-overview/.valuation-card/.snapshot-row/.tabs-wrapper/.temp-sources/.fear-greed/.conversion-section 等）+ 死变量 `tempSource`。需 cleanup。
- 自算 `self_calc`（backend SelfCalcFetcher）当前含 PE，需改造成基于股债利差、不依赖 PE。

## 后端事实（已核实）
- 恐惧贪婪文案分级见 `backend/app/services/thermometer/constants.py: label_fear`。
- 温度接口 `/api/temperature/overview` 已带 per-source `source` 字段与 `links`（jisilu/jiucaishuo/qieman/youzhiyouxing/eastmoney 官网）。
- 综合温度合成接口后端尚未实现（前端 temp-card-main 为占位）。

## v3 追加决策（同一轮讨论，用户细化）
- **一级锚点不等宽**：综合温度(2) : 恐惧贪婪指数(1) : 自算·股债利差(1)，卡片大小不同，综合温度最大做 hero。
- **综合温度占位卡继续占一级 hero 位**（用户接受空位，等后端合成接口上线再填真实值）。
- **恐惧贪婪文字直接用后端 label，不自分级**（用户指出抓取数据已含文字解释，无需前端再分 4 档）。pill 颜色按数值/档位映射：恐惧类→绿，贪婪类→红，中性→灰。
- **来源暴露改为页面底部常驻静态来源列表**（点击跳官网），替代此前"逐卡 hover chip"方案，减少 clutter。
